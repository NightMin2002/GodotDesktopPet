# 游戏 UI 组件规划

> BaseGame 层通用游戏 UI 组件清单。目标：每个新游戏只关注玩法逻辑，UI 品质有底线保障。

---

## 现状

BaseGame 当前提供的共享 UI：

| 已有 | 说明 |
|------|------|
| `_create_game_panel_bg()` | 面板背景 (深色半透明 + 主题色边框) |
| `_create_panel_skeleton()` | 面板骨架 (PanelContainer + Margin + VBox) |
| `_create_compare_row()` | 双方战绩对比行 |
| `_create_score_rich_label()` | BBCode 战绩标签 |
| `_show_xp_popup()` | XP 飘字动画 |
| GameChrome | 悬浮组件 (标题气泡/侧边按钮/连接线/发言气泡/重开按钮) |
| 教程面板 | 分步骤简报 + 预览动画 |
| 自玩基础设施 | 定时器/淡入淡出/接管逻辑 |

缺失的是**游戏内部**的通用 UI 组件。

---

## 规划组件清单

### 1. 结算屏 (GameOverlay)

游戏结束时的全屏覆盖层，替代当前的"宠物说句话就完了"。

**需求：**
- 三种结算类型：胜利 / 失败 / 平局，各自独立视觉风格
- 本局数据回顾（用时、步数、得分等，由子类提供数据字典）
- 宠物评语（从话术池抽取，显示在结算屏内）
- 操作按钮组：再来一局 / 关闭
- 入场动画：从中心展开 + 背景模糊化

**接口草案：**
```gdscript
## 子类覆写: 提供本局数据
func get_result_summary() -> Dictionary:
    return {"用时": "1:23", "步数": "42"}

## 子类覆写: 各结算类型的话术池
func get_win_lines() -> Array: return ["...算你赢。"]
func get_lose_lines() -> Array: return ["意料之中。"]
func get_draw_lines() -> Array: return ["...势均力敌。"]
```

### 2. 游戏内 HUD (GameHUD)

面板顶部/底部的实时信息条。

**需求：**
- 计分器（支持整数累加动画，数字滚动效果）
- 计时器（正计时/倒计时两种模式）
- 连击/连锁计数器（带光晕放大动画）
- 状态指示器（回合标记、当前玩家等）
- 组件化：子类按需选取组合，不用的不显示

**接口草案：**
```gdscript
## 子类在 start() 中配置
_hud.add_score("得分", 0)
_hud.add_timer(countdown_seconds)  # 0=正计时
_hud.add_indicator("回合", "玩家")

## 游戏中更新
_hud.set_score("得分", new_value)  # 自动滚动动画
_hud.set_indicator("回合", "宠物")
```

### 3. 过场系统 (GamePhase)

管理游戏各阶段之间的视觉转场。

**需求：**
- 阶段枚举：READY → PLAYING → PAUSED → GAME_OVER
- 开局倒计时（3-2-1-GO，大字居中，每个数字有缩放+淡出动画）
- 阶段切换时自动触发转场（可选，子类可跳过）
- PAUSED 状态：灰化面板 + 居中"已暂停"提示

**接口草案：**
```gdscript
## 启动时
_phase.start_countdown(3, func(): _begin_game())

## 游戏结束时
_phase.transition_to(GamePhase.GAME_OVER, result_data)
```

### 4. 难度/模式选择 (GameSetup)

开局前的配置面板，嵌入游戏面板内。

**需求：**
- 难度选择（简单/普通/困难，三态切换按钮）
- 自定义参数（如棋盘大小、限时等，子类声明式配置）
- 确认按钮触发正式开局
- 选项持久化（记住上次选择）

**接口草案：**
```gdscript
## 子类覆写: 声明配置项
func get_setup_options() -> Array[Dictionary]:
    return [
        {"id": "difficulty", "label": "难度", "type": "select",
         "values": ["简单", "普通", "困难"], "default": 1},
        {"id": "board_size", "label": "棋盘", "type": "select",
         "values": ["8x8", "10x10"], "default": 0},
    ]

## 基类在配置确认后调用
func _on_setup_confirmed(config: Dictionary) -> void:
    # config = {"difficulty": 1, "board_size": 0}
```

### 5. 操作指引 (GameGuide)

局内实时操作提示（比教程面板更轻量）。

**需求：**
- 底部半透明提示条（"左键放置 / 右键标记"）
- 首次游戏自动显示，之后可手动关闭
- 支持动态切换文字（不同阶段不同提示）
- 记忆"已看过"状态，不重复打扰

---

## 优先级排序

| 优先级 | 组件 | 理由 |
|--------|------|------|
| P0 | 结算屏 | 当前最明显的缺失，每局结束体验都差 |
| P1 | 游戏内 HUD | 信息展示是基本功，多数游戏需要 |
| P2 | 过场系统 | 提升节奏感，但不影响功能 |
| P3 | 难度选择 | 增值功能，现有游戏可后补 |
| P3 | 操作指引 | 教程面板已部分覆盖 |

---

## 实现原则

1. **全部在 BaseGame 层实现**，子类通过覆写 hook 提供数据，不需要操心 UI 细节
2. **组件化可选**，不用的组件零开销（懒创建）
3. **视觉风格统一**，自动跟随 `EventBus.ui_hue` 主题色
4. **自玩兼容**，所有组件在自玩模式下正确降级（如结算屏自动跳过/简化）
5. **全息屏友好**，组件渲染在 SubViewport 内，自动出现在全息投影中
