## 二、数据模型与持久化

### 单条待办结构

```gdscript
{
    "id": "1715520000_12345",   # unix时间戳_随机数
    "text": "任务名称",          # 标题
    "notes": "备注内容",         # 右栏详细备注
    "done": false,              # 完成状态
    "created": "2025-05-12",    # 创建日期
}
```

### 存储方式

通过 `SettingsManager` 使用 `ConfigFile` API，存在 `user://settings.cfg` 的 `[todos]` 节点：

```ini
[todos]
list=[{"id":"1715520000_12345","text":"示例","notes":"","done":false,"created":"2025-05-12"}]
```

### 读写接口

```gdscript
# 读取
var todos: Array = SettingsManager.get_todos()

# 保存 (整个数组替换)
SettingsManager.save_todos(todos)
```

## 三、待办面板

### 布局结构

```
PanelContainer (theme.create_panel() 返回)
├── VBoxContainer (outer)
│   ├── HBoxContainer (标题栏, 可拖拽)
│   │   ├── Label "待办清单"
│   │   ├── Spacer
│   │   ├── Button "主题名" (循环切换)
│   │   └── Button "关闭"
│   │
│   ├── HSeparator
│   ├── Control (进度指示器, 独占一行, 由主题工厂创建)
│   │
│   ├── HBoxContainer (主体双栏)
│   │   ├── VBoxContainer (左栏)
│   │   │   ├── ScrollContainer
│   │   │   │   └── VBoxContainer (list_box, 待办卡片列表)
│   │   │   └── Button "+ 新建待办"
│   │   │
│   │   ├── VSeparator
│   │   │
│   │   └── VBoxContainer (右栏)
│   │       ├── LineEdit (标题编辑)
│   │       ├── HSeparator
│   │       ├── TextEdit (备注编辑)
│   │       └── PanelContainer (已保存徽章)
│   │
│   └── HBoxContainer (底部, 预留)
```

### 关键交互

- **拖拽移动**: 标题栏 `gui_input` 捕获拖拽，`_clamp_pos` 限制屏幕边界
- **选中待办**: 左栏卡片点击 → `_selected_idx` 更新 → 右栏刷新
- **编辑备注**: 右栏 TextEdit 输入 → 0.6s 防抖 Timer → 自动保存 → "已保存"徽章
- **主题切换**: 标题栏按钮循环切换，选择持久化到 `settings.cfg`

### 面板开关动画

```gdscript
# 打开: 弹性缩放 + 淡入
scale = Vector2(0.85, 0.85)  →  Vector2.ONE  (0.25s, ease out)
modulate.a = 0.0  →  1.0

# 关闭: 缩小 + 淡出
scale → Vector2(0.92, 0.92)  (0.15s)
modulate.a → 0.0
```

## 四、主动提醒

### 触发条件

全部满足才触发：

1. 启动缓冲已过 (8~15 秒随机)
2. 宠物处于 idle 状态
3. 存在未完成的待办
4. 非深夜时段 (23:00~6:00 不打扰)
5. 非游戏中
6. 当日未触发过

### UI 结构

```
CanvasLayer
├── Panel (气泡背景, 含尖角三角形)
│   └── Label "你有 N 条待办未完成哦"
│
├── Button "知道了" (左侧)
└── Button "查看待办" (右侧)
```

气泡和按钮位置跟随宠物的 `get_ui_anchor()` 接口，屏幕边界自适应。

### 调试

右键菜单 → 宠物 → 触发待办提醒 (EventBus.trigger_todo_prompt 信号)

## 五、主题系统

### 设计原则

1. **基类 = 合同 + 中性兜底**: `TodoThemeBase` 定义所有组件工厂方法，提供只使用种子色的中性默认实现
2. **主题 = 自包含**: 每个主题文件包含自己的边框类 + 所有需要覆写的工厂方法
3. **新增组件零破坏**: 骨架新增 `make_xxx()` → 基类加中性默认 → 已有主题不需要改

### 种子色推算

`_from_seeds(base, text, accent, danger, alpha)` 从 5 个参数推算约 34 个配色属性：

| 参数 | 说明 | 影响范围 |
|------|------|---------|
| `base` | 基底色 | 所有 `bg_*` 背景色 (HSV 亮度偏移) |
| `text` | 主文字色 | 所有 `tx_*` 文字色、`bd_*` 边框色 |
| `accent` | 强调色 | 完成/选中/新建按钮 |
| `danger` | 危险色 | 删除/关闭按钮 |
| `alpha` | 整体透明度 | 所有背景色 alpha 系数 |

自动区分明暗模式 (`base.v < 0.4` 为暗色)，背景偏移方向自适应。

### 组件工厂方法

| 方法 | 返回/作用 | 默认行为 |
|------|----------|---------|
| `create_panel()` | PanelContainer | 纯色底 + 1px 边框 |
| `make_card_style(done, sel)` | StyleBoxFlat | 种子色卡片 + 选中高亮 |
| `make_card_hover_style(base)` | StyleBoxFlat | alpha+border 微调 |
| `make_add_button(text)` | Button | 中性按钮 |
| `make_close_button(text)` | Button | 中性按钮 (danger 色) |
| `make_delete_button(text)` | Button | 透明底文字按钮 |
| `make_theme_button(text)` | Button | 中性按钮 (accent 色) |
| `make_checkbox(done)` | Button | 方框 + 对勾 |
| `make_separator()` | HSeparator | 纯色线 |
| `make_scrollbar()` | Control | 像素风竖轨道 + 方块拇指，支持拖拽/点击/滚轮 |
| `apply_note_edit_style(edit)` | void | 种子色输入框 |
| `apply_note_title_style(title)` | void | 透明底 + focus 下划线 |
| `apply_save_badge_style(badge, l)` | void | 圆角胶囊徽章 |
| `apply_vsep_style(vsep)` | StyleBoxFlat | 种子色分隔线 |
| `make_progress_indicator()` | Control | 像素风进度条 (_draw 自绘) |
| `update_progress_indicator(ctrl, done, total)` | void | 更新进度填充和文字 |
| `apply_card_title_style(l, done, sel)` | void | 字色切换 |
| `apply_*_style(...)` | void | 字号+字色 |

### 辅助构建器 (子类可选使用)

| 方法 | 风格 |
|------|------|
| `_make_btn(text, bg, border, fg, hover_fg, size)` | 中性按钮 (默认工厂用) |
| `_build_pill_btn(text, bg, hover_bg, size)` | 圆角胶囊按钮 |
| `_build_text_btn(text, normal, hover)` | 纯文字按钮 |

## 六、新建主题指南

### 快速开始

1. 复制 `_theme_template.gd` 到 `ui/todo_themes/` 并重命名
2. 修改 `class_name`
3. 调整 `_from_seeds()` 的 5 个种子色参数
4. 按需覆写工厂方法
5. 在 `todo_panel.gd` 的 `_THEME_NAMES` 加名称、`_create_theme()` 的 match 加分支

### 最小主题 (纯换色)

```gdscript
class_name TodoThemeAmber extends TodoThemeBase

func _init() -> void:
    _from_seeds(
        Color(0.06, 0.04, 0.02),   # base: 暖深色
        Color(0.95, 0.75, 0.20),   # text: 琥珀
        Color(0.95, 0.75, 0.20),   # accent: 同色
        Color(0.95, 0.20, 0.15),   # danger: 红
        0.97                        # alpha
    )
```

这样就能得到一套完整的琥珀主题，所有组件都自动跟随种子色。

### 完整主题 (换色 + 自绘边框 + 覆写组件)

参见 `_theme_template.gd` 中的完整注释和示例。要点：

- **自定义边框**: 写一个内嵌 `PanelContainer` 子类 + `_draw()` 自绘 → 覆写 `create_panel()`
- **覆写复选框**: 任意形态 — 用特殊符号、_draw 手绘、动画
- **覆写按钮**: 调用 `_build_pill_btn` 或完全自建
- **覆写编辑框**: 透明化融入面板、去除边框等
- **覆写滚动条**: 继承 `TodoScrollbar` 覆写 `_draw_track()` / `_draw_thumb()`

### 架构补充

**虚拟滚动列表**: 左栏待办列表使用节点池 + 视窗裁剪，场景树中始终只保持约 20 个卡片节点。通过状态指纹比对跳过未变化的槽位。

**自定义滚动条**: 通过 `make_scrollbar()` 工厂方法提供，默认像素风竖轨道，支持拖拽拇指、点击跳转和滚轮穿透。拥有独立固定宽度空间，不会引起布局跳动。

**滚动指示器**: 当列表内容超出视口时，上下边缘显示形如 `▲ 5` / `▼ 12` 的计数徽章，实时显示被隐藏的条目数量。

## 七、新增骨架组件指南

当待办面板需要新增 UI 组件时（比如优先级标签、截止日期选择器等）：

### 操作步骤

1. 在 `todo_panel.gd` 中编写布局代码，调用主题方法：
   ```gdscript
   var tag = theme.make_priority_tag(level)
   ```

2. 在 `todo_theme_base.gd` 中添加中性默认实现：
   ```gdscript
   func make_priority_tag(level: int) -> Label:
       var l = Label.new()
       l.text = str(level)
       l.add_theme_font_size_override("font_size", 12)
       l.add_theme_color_override("font_color", accent_soft)
       return l
   ```

3. 完成。已有主题不需要改动，它们会自动获得中性默认的组件。

4. 各主题可以在有空时覆写出自己风格的版本：
   ```gdscript
   # 某个具体主题
   func make_priority_tag(level: int) -> Label:
       # ... 自己的风格实现
   ```

### 原则

> 基类里每个 `make_xxx()` / `apply_xxx()` 都必须有能独立工作的默认实现，且只使用种子色派生属性。
