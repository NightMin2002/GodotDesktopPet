## 1. 编辑器快速上手

### 界面布局

```
┌─────────────────────────────────────────────────────┐
│  场景树(左上)  │       2D/3D 视口 (中央)      │ 检视器(右) │
│  ──────────── │                              │ ────────── │
│  Main         │   ← 你的游戏画面预览 →       │ 属性面板    │
│   └ Pet       │                              │ (选中节点   │
│     └ Coll..  │                              │  的属性)    │
│               │                              │            │
├───────────────┴──────────────────────────────┴────────────┤
│              输出 / 调试器 / 搜索结果 (底部)                │
└──────────────────────────────────────────────────────────┘
```

### 最常用操作

| 快捷键 | 作用 |
|--------|------|
| **F5** | 运行项目 |
| **F6** | 运行当前场景 |
| **Ctrl+S** | 保存当前场景 |
| **Ctrl+Shift+S** | 另存场景 |
| **Ctrl+Z / Y** | 撤销 / 重做 |
| **F** | 在2D视口中聚焦选中节点 |

### 怎么编辑脚本？

1. 在「场景树」中选中一个节点（比如 Pet）
2. 右边「检视器」顶部会显示它挂载的脚本
3. **双击脚本名** 或点击卷轴图标 📜 → 进入脚本编辑器
4. 也可以在底部「文件系统」面板中双击 `.gd` 文件

## 2. GDScript 语法速查

GDScript 语法非常接近 Python，如果你写过 Python 或 TypeScript，上手极快。

### 基础语法

```gdscript
# 变量声明
var name: String = "史莱姆"       # 有类型声明
var speed := 100.0                # 类型推断 (:= 自动推断类型)
const MAX_HP := 100               # 常量

# 函数
func say_hello(who: String) -> void:
    print("你好, ", who)

# 条件
if speed > 50:
    print("快")
elif speed > 20:
    print("一般")
else:
    print("慢")

# 循环
for i in range(10):
    print(i)

for item in ["苹果", "香蕉"]:
    print(item)

# 数组和字典
var fruits := ["苹果", "香蕉"]
var pet := {"name": "狼", "hp": 100}
```

### 与 TypeScript 对比

| TypeScript | GDScript | 说明 |
|-----------|----------|------|
| `let x: number = 5` | `var x: float = 5.0` | 变量声明 |
| `const Y = 10` | `const Y := 10` | 常量 |
| `function foo(): void {}` | `func foo() -> void:` | 函数 |
| `this.name` | `self.name` 或直接 `name` | 访问自身属性 |
| `console.log()` | `print()` | 打印调试 |
| `setTimeout(fn, 1000)` | `await get_tree().create_timer(1.0).timeout` | 延时 |
| `class Foo extends Bar` | `class_name Foo` + `extends Bar` | 类继承 |
| `null` | `null` | 空值 |
| `===` | `==` | 相等比较 |
| `!==` | `!=` | 不等比较 |

### 内置类型速查

```gdscript
Vector2(x, y)        # 二维向量 (最常用！位置、速度、方向都是它)
Color(r, g, b, a)    # 颜色 (0~1 范围)
Rect2(x, y, w, h)    # 矩形区域
```

## 3. 核心概念

### 3.1 节点与场景

- **节点 (Node)** = 最小功能单元。每种节点有不同能力：
  - `Node2D` — 有位置的 2D 节点
  - `RigidBody2D` — 受物理影响的刚体
  - `StaticBody2D` — 不动的物理墙
  - `CollisionShape2D` — 碰撞形状 (必须是物理体的子节点)
  - `Sprite2D` — 显示一张图片
  - `Label` — 显示文本

- **场景 (Scene) `.tscn`** = 一棵节点树的**模板**。可以被实例化(复制)到其他场景中。

```
pet.tscn 的结构:
Pet (RigidBody2D)          ← 根节点
  └── CollisionShape2D     ← 碰撞形状子节点
```

### 3.2 信号 (Signal) — Godot 的事件系统

```gdscript
# 定义信号 (在脚本顶部)
signal health_changed(new_hp: int)

# 发射信号
health_changed.emit(80)

# 连接信号 (在另一个脚本中)
pet.health_changed.connect(_on_health_changed)

func _on_health_changed(new_hp: int) -> void:
    print("血量变了: ", new_hp)
```

### 3.3 生命周期函数

```gdscript
# 节点进入场景树时调用 (相当于 Vue 的 mounted)
func _ready() -> void:
    pass

# 每渲染帧调用 (帧率不固定，用于视觉更新)
func _process(delta: float) -> void:
    pass

# 每物理帧调用 (固定60fps，用于物理计算)
func _physics_process(delta: float) -> void:
    pass

# 接收输入事件 (键盘、鼠标)
func _input(event: InputEvent) -> void:
    pass

# 节点离开场景树时调用 (相当于 Vue 的 unmounted)
func _exit_tree() -> void:
    pass
```

### 3.4 `_process` vs `_physics_process`

| | `_process(delta)` | `_physics_process(delta)` |
|-|-------------------|--------------------------|
| 调用频率 | 跟随显示器刷新率 (60~144fps) | 固定 60fps |
| 用途 | UI更新、动画、视觉效果 | 物理运动、碰撞、施加力 |
| delta 含义 | 上一帧到现在的秒数 | 固定 1/60 ≈ 0.0167 秒 |

> ⚠️ **物理操作（如 `apply_force`）必须放在 `_physics_process` 中**，放在 `_process` 中会因帧率波动导致行为不稳定。

## 4. 调试技巧

### 打印调试

```gdscript
print("变量值: ", my_var)        # 最基本的调试
print("[模块名] 状态: ", state)   # 带标签的调试信息
```

输出会显示在 Godot 底部的「输出」面板中。

### 断点调试

1. 在脚本编辑器中，点击行号左边 → 出现红点 = 断点
2. 按 F5 运行 → 程序会在断点处暂停
3. 底部「调试器」面板可以查看变量值

### 远程场景树

运行项目后，在「场景」面板顶部会出现「远程」按钮，点击后可以看到**运行时**的实际节点树，对排查问题非常有用。

## 5. 常见问题 FAQ

### Q: 怎么添加新节点？
在场景树中右键 → 「添加子节点」→ 搜索节点类型

### Q: 怎么给节点挂脚本？
选中节点 → 右键 → 「附加脚本」→ 选择路径和模板

### Q: 场景文件 `.tscn` 能用文本编辑器打开吗？
能！它是纯文本格式。但不建议手动编辑，用 Godot 编辑器操作更安全。

### Q: 为什么节点名旁边有个卷轴图标 📜？
说明这个节点上挂载了一个脚本。

### Q: 怎么在代码中获取其他节点？
```gdscript
$CollisionShape2D              # 获取子节点 (相对路径)
get_node("CollisionShape2D")   # 同上的完整写法
get_parent()                   # 获取父节点
get_tree().root                # 获取场景树根节点
```

### Q: `preload` 和 `load` 有什么区别？
```gdscript
var s = preload("res://pet.tscn")  # 编译时加载 (推荐，更快)
var s = load("res://pet.tscn")     # 运行时加载 (按需加载时用)
```

### Q: `res://` 是什么？
Godot 的项目根路径前缀。`res://main.gd` = 项目根目录下的 main.gd。
