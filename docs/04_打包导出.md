# 📦 打包导出教程

> 将 Godot 项目导出为独立的 `.exe` 文件，无需安装 Godot 即可运行。

---

## 一、安装导出模板 (只需一次)

导出模板是 Godot 用来构建最终可执行文件的核心组件，每个 Godot 版本需要对应的模板。

### 步骤

1. 打开 Godot 编辑器
2. 顶部菜单 → **编辑器 → 管理导出模板**
3. 在弹出窗口中看到当前版本号 (如 4.6.2.stable)
4. 选择下载镜像 (推荐 **GitHub Mirror**)
5. 点击 **下载并安装**
6. 等待下载完成 (~500MB)

> ⚠️ 模板文件约 500MB，需要稳定网络。如果下载失败，可以从 [GitHub Releases](https://github.com/godotengine/godot/releases) 手动下载 `Godot_v4.x-stable_export_templates.tpz`，然后用「从文件安装」按钮导入。

---

## 二、配置导出预设

1. 顶部菜单 → **项目 → 导出** (或快捷键 Ctrl+Shift+E)
2. 点击左上角 **添加...** → 选择 **Windows Desktop**
3. 配置以下选项:

### 关键设置

| 设置项 | 推荐值 | 说明 |
|--------|--------|------|
| **导出路径** | `builds/DesktopPet.exe` | 输出文件位置 |
| **嵌入 PCK** | ✅ 开启 | 将资源打包进 exe，只需分发一个文件 |
| **导出调试** | ❌ 关闭 (正式版) | 调试版会带控制台窗口 |
| **导出控制台包装器** | ❌ 关闭 | 不需要控制台窗口 |

### 应用程序设置 (Application)

| 设置项 | 说明 |
|--------|------|
| **产品名称** | `Desktop Pet` |
| **图标** | 设置 `.ico` 文件路径 (可选，设置自定义图标) |

> 💡 **自定义图标**: 如果想要自定义 exe 图标，需要先下载 [rcedit](https://github.com/electron/rcedit/releases)，然后在 **编辑器 → 编辑器设置 → 导出 → Windows** 中设置 rcedit 路径。之后在导出预设中设置 `.ico` 图标文件。

---

## 三、导出

1. 在导出窗口中确认 **Windows Desktop** 预设已选中
2. 点击 **导出项目**
3. 选择保存目录和文件名
4. 取消勾选「导出调试」(如果是正式版)
5. 点击 **保存**
6. 等待导出完成

### 导出结果

如果启用了「嵌入 PCK」:
```
builds/
└── DesktopPet.exe     ← 只需这一个文件！双击即可运行
```

如果没有启用:
```
builds/
├── DesktopPet.exe     ← 可执行文件
└── DesktopPet.pck     ← 资源包 (必须和 exe 放一起)
```

## 四、分发给别人

### 最简方式: 直接发 exe

1. 把 `DesktopPet.exe` 发给别人
2. 对方双击即可运行，**不需要安装 Godot**
3. 首次运行 Windows 可能弹出安全提示，点「仍要运行」即可

### 进阶: 制作安装器

如果需要更专业的分发方式:

| 工具 | 特点 |
|------|------|
| [Inno Setup](https://jrsoftware.org/isinfo.php) | 免费，Windows 安装器制作工具 |
| [NSIS](https://nsis.sourceforge.io/) | 免费开源，脚本驱动 |
| 打成 .zip | 最简单，让用户自己解压 |

## 五、特别注意

### 🚨 透明窗口导出注意事项

桌面宠物的透明窗口功能在导出后可能需要额外确认:

1. **渲染器必须是 Compatibility** — 在项目设置中确认，Forward+ 导出后透明可能失效
2. **Windows 兼容性** — 在 Windows 10/11 上测试，确保透明度正常
3. **不要勾选「使用 D3D12」** — 如果导出预设中有此选项，保持关闭

### 📁 建议在项目中创建 builds 目录

```
Desktop_Pet/
├── builds/           ← 导出目录 (加入 .gitignore)
│   └── DesktopPet.exe
├── project.godot
├── main.tscn
└── ...
```

在项目根目录创建 `.gitignore`:
```
# 导出构建
builds/

# Godot 生成文件
.godot/
*.import
```
