# 📦 打包导出教程

> 将 Godot 项目导出为独立可执行文件，再通过 Inno Setup 打包为一键安装器。

---

## 整体流程

```
Godot 导出 → builds/ 目录 (exe + .NET DLL) → Inno Setup 编译 → dist/ 安装器
```

由于项目使用了 C# (.NET) 代码，导出后 `builds/` 目录下会包含主程序 exe 和约 200+ 个 .NET 运行时 DLL，**不能直接分发单个 exe**。需要通过 Inno Setup 将整个目录打包成安装器。

---

## 一、安装导出模板 (首次)

导出模板是 Godot 构建最终可执行文件的核心组件，每个 Godot 版本需要对应模板。

1. 打开 Godot 编辑器
2. 顶部菜单 → **编辑器 → 管理导出模板**
3. 确认当前版本号 (如 `4.6.2.stable`)
4. 选择下载镜像 (推荐 **GitHub Mirror**)
5. 点击 **下载并安装** (约 500MB)

> 💡 如果下载失败，可从 [Godot GitHub Releases](https://github.com/godotengine/godot/releases) 手动下载 `Godot_v4.x-stable_export_templates.tpz`，然后用「从文件安装」按钮导入。

---

## 二、配置导出预设

1. 顶部菜单 → **项目 → 导出** (快捷键 `Ctrl+Shift+E`)
2. 点击左上角 **添加...** → 选择 **Windows Desktop**
3. 配置以下选项:

### 关键设置

| 设置项 | 推荐值 | 说明 |
|--------|--------|------|
| 导出路径 | `builds/Desktop Pet.exe` | 输出文件位置 |
| 嵌入 PCK | ✅ 开启 | 将资源打包进 exe，减少散落文件 |
| 导出调试 | ❌ 关闭 (正式版) | 调试版会带控制台窗口 |
| 导出控制台包装器 | ❌ 关闭 | 不需要额外的控制台窗口 |

### 透明窗口注意事项

| 检查项 | 要求 |
|--------|------|
| 渲染器 | 必须为 **Compatibility** (GL Compatibility)。Forward+ 导出后透明可能失效 |
| D3D12 | 如果导出预设中有「使用 D3D12」选项，**保持关闭** |

---

## 三、导出项目

1. 在导出窗口确认 **Windows Desktop** 预设已选中
2. 点击 **导出项目**
3. 路径选择 `builds/Desktop Pet.exe`
4. 取消勾选「导出调试」
5. 点击 **保存**

导出完成后 `builds/` 目录结构：

```
builds/
├── Desktop Pet.exe                     ← 主程序 (~100MB)
├── Desktop Pet.console.exe             ← 控制台调试入口 (可忽略)
└── data_Desktop Pet_windows_x86_64/    ← .NET 运行时文件 (~200个 DLL)
    ├── Desktop Pet.dll                 ← 你的 C# 代码编译产物
    ├── GodotSharp.dll                  ← Godot C# 绑定
    ├── coreclr.dll                     ← .NET 运行时核心
    └── System.*.dll                    ← .NET 框架库
```

## 四、安装 Inno Setup

[Inno Setup](https://jrsoftware.org/isinfo.php) 是免费的 Windows 安装器制作工具，适合个人和消费级软件分发。

### 安装方式

**方式一：官网下载 (推荐)**

前往 [jrsoftware.org/isdl.php](https://jrsoftware.org/isdl.php) 下载最新版 `innosetup-6.x.x.exe`，双击安装即可。

**方式二：命令行安装**

```powershell
winget install --id JRSoftware.InnoSetup -e
```

---

## 五、打包安装器

项目根目录下已经有配置好的 `installer.iss` 脚本。

### 编译步骤

1. 双击 `installer.iss` → 自动用 Inno Setup Compiler 打开
2. 按 **F9** 或点击工具栏的 **编译** 按钮
3. 等待编译完成 → 安装器生成到 `dist/桌面宠物.exe`

### 验证

双击 `dist/桌面宠物.exe` 测试安装流程是否正常：
- 安装路径默认为 `C:\Program Files\pet\`
- 可选创建桌面快捷方式
- 安装完成后可选立即启动

## 六、修改游戏名与版本迭代

当你需要修改应用名字（如改为“赛博宠物”）或进行版本升级时，Godot 导出设置和 Inno Setup（`installer.iss`）需要**配对操作**。

### 1. Godot 导出端操作
1. 顶部菜单 → **项目 → 导出**。
2. 修改 **导出路径**的 exe 名称：将 `builds/Desktop Pet.exe` 里面的文件名改为如 `builds/CyberPet.exe`（如果无需改名则不理会）。
3. 在右侧属性表往下拉找到 **Application** 栏目：把 `Product Name` 改为你想显示的名称（如 `赛博宠物`）。
4. 点击“导出项目”。

### 2. Inno Setup 打包端操作
在使用 Inno Setup 编译器打开 `installer.iss` 时，只需要修改顶部定义的三行变量即可：

```iss
; 1. UI显示的应用名称 (快捷方式、控制面板里也是这个名字)
#define MyAppName "赛博宠物"

; 2. 【核心】软件版本号：每次发布更新必改
#define MyAppVersion "1.2"

; 3. 输出源文件校验名：必须和你在 Godot 导出的那个 exe 名字一模一样
#define MyAppExeName "CyberPet.exe"
```

你现在不需要再手动修改底部配置了。底部的安装生成命令已经被设为了动态变量（`OutputBaseFilename={#MyAppName}-{#MyAppVersion}-Setup`），按下 **F9** 编译后，`dist/` 目录下就会自动掉落一个带版本管理的神仙安装包（如 `赛博宠物-1.2-Setup.exe`）。

> ⚠️ **覆盖更新核心逻辑**：Inno Setup 会通过 `AppId` 判断这是否是同一款软件。只要这段 GUID（`{958D0297-DFE0-4B54-9DD8-35C2248B2267}`）永远不乱动，用户直接双击 1.2 的安装包就会平滑覆盖 1.0 版本。

## 七、ISS 脚本关键字段说明

```iss
#define MyAppName "桌面宠物"           ; 应用名称 (显示在安装界面和控制面板)
#define MyAppVersion "1.0"             ; 版本号 (每次发布需递增)
#define MyAppExeName "Desktop Pet.exe" ; 主程序文件名

[Setup]
AppId={{958D0297-...}                  ; 唯一标识符 (永远不要改!)
DefaultDirName={autopf}\pet            ; 默认安装到 Program Files\pet
OutputDir=dist                         ; 安装器输出目录
OutputBaseFilename=桌面宠物             ; 安装器文件名
ArchitecturesAllowed=x64compatible     ; 仅支持 64 位系统
SolidCompression=yes                   ; 启用固实压缩 (减小体积)
WizardStyle=modern dynamic            ; 现代化安装界面风格

[Files]
Source: "builds\*"; DestDir: "{app}"; Flags: ignoreversion recursesubdirs
; ↑ 将 builds/ 下所有文件递归复制到安装目录
```
