# 发版流程

## 版本号位置

发版时需要同步修改两个文件的版本号，`release.ps1` 脚本会自动处理：

| 文件 | 字段 | 示例 |
|------|------|------|
| `core/update_checker.gd` | `const CURRENT_VERSION` | `"1.8"` |
| `installer.iss` | `#define MyAppVersion` | `"1.8"` |

## 发版步骤

### 1. 跑发版脚本（改版本号 + Git 推送）

```powershell
.\release.ps1 -Version "1.8"
```

脚本自动完成：
- 修改两个文件的版本号
- `git commit -m "release: v1.8"`
- `git tag v1.8`
- `git push` 代码和标签

### 2. Godot 导出项目

在 Godot 编辑器中导出 Windows 桌面版到 `builds/` 目录。

> **必须在跑完脚本之后再导出**，否则导出的二进制文件里烙印的还是旧版本号。

### 3. Inno Setup 编译安装包

打开 `installer.iss`，编译生成安装包到 `dist/` 目录。
输出文件名格式：`桌面宠物-1.8-Setup.exe`

### 4. 上传 GitHub Release

打开链接创建 Release（脚本会打印出来）：

```
https://github.com/NightMin2002/GodotDesktopPet/releases/new?tag=v1.8
```

1. 填写标题（如 `v1.8`）和更新说明
2. 拖拽安装包到附件区域
3. 点击发布

## 更新检测原理

- 宠物启动 15 秒后，`update_checker.gd` 请求 GitHub Releases API
- 比对本地 `CURRENT_VERSION` 与远程 `tag_name`
- 有新版则气泡通知用户
- 装置终端「关于」Tab 也会显示实时更新状态

## 注意事项

- GitHub Release 单个附件上限 2GB，100MB 安装包没有问题
- Inno Setup 同 AppId 自动支持覆盖安装，用户不需要卸载旧版
- 未来如果安装了 `gh` CLI (`winget install GitHub.cli`)，脚本可以自动上传附件
