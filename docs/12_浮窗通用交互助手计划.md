# 浮窗通用交互助手重构计划

## 目标

把多个低层级浮窗重复实现的交互基础设施抽成一个通用助手，统一处理：

- DWM 精确命中区域注册与清理
- `EventBus._active_panel_rects` 活动矩形登记
- 宠物优先输入拦截
- 多面板重叠时的点击置顶判断
- 面板关闭或退出树时的兜底清理

本次重构只处理浮窗基础交互，不改面板业务逻辑、不改视觉布局、不改搜索、游戏、终端数据流。

## 第一阶段接入范围

优先接入规则最一致的三个面板：

| 文件检索终端 | `ui/file_search/file_search_panel.gd` | overlay 注册、宠物优先输入、点击置顶、关闭清理 |
| 游戏终端 | `ui/game_terminal/game_terminal.gd` | overlay 注册、宠物优先输入、点击置顶、关闭清理 |
| 装置终端 | `ui/pet_profile_panel.gd` | overlay 注册、宠物优先输入、点击置顶、关闭清理 |

## 设计方案

新增 `core/floating_panel_helper.gd`：

- 类型：`class_name FloatingPanelHelper extends RefCounted`
- 持有宿主面板引用、`panel_id`、日志 owner 名称、`panel` 节点
- 通过宿主回调读取：
  - 是否打开：`host.is_open`
  - 当前层级：`host.layer`
  - 面板矩形：`Rect2(panel.position, panel.size 或指定尺寸)`
  - 主节点：优先从场景树查找 `Main`

对外提供方法：

- `setup(host, panel_id, owner, panel_getter, open_getter, rect_getter)`
- `sync()`：打开时注册 overlay 和活动矩形
- `cleanup()`：关闭或 `_exit_tree` 时清理 overlay 和活动矩形
- `handle_input(event)`：宠物优先输入 + 点击置顶
- `request_focus()`：触发 `panel_focus_requested`
- `apply_focus(panel_id)`：根据焦点切换 `layer = -1/-2`
- `find_pet_at_mouse()`：统一遍历所有宠物命中

## 验收清单

### 基础行为

- 文件检索终端可打开、关闭、拖拽
- 游戏终端可打开、关闭、拖拽，游戏启动/返回大厅正常
- 装置终端可打开、关闭、拖拽，Tab 切换正常
- ESC 仍可关闭文件检索终端

### 穿透行为

- 面板区域可点击，不穿透到桌面
- 面板外区域继续穿透到桌面
- 面板关闭后不残留不可见阻挡区域
- 多个面板重叠时，点击顶层以下的面板只在未被更高层覆盖时置顶

### 宠物优先

- 宠物位于面板上方时，左键仍可拖拽宠物
- 宠物位于面板上方时，右键仍可打开宠物菜单
- 面板按钮没有被宠物遮挡时，按钮点击正常

### 回归检查

- `git diff --check`
- `dotnet build "Desktop Pet.csproj"`
- 若本机有 Godot CLI，再运行 Godot 脚本解析检查；没有则记录无法执行
