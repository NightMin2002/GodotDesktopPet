# 🚀 机械单眼桌面宠物：赛博入侵进化构想 (Roadmap)

随着底层的 Win32 API 穿透方案（CONFINED / REPELLED 模式）与全息 UI 体系的圆满建成，宠物已经具备了完美感知桌面物理空间的能力。

本阶段的规划方向将朝着**更高权限的系统级深潜（System Deep.Dive）**与**打破次元壁的现实联结（Reality Sync）**展开。我们要剥离传统桌宠“只是个屏幕特效”的固有印象，将其进化为一个能全知全视、拥有真实存在感的高级“赛博管家”。

## 一、 认知降维打击 (Cognitive Deep Dive)

### 1. 视窗读心术引擎 (Browser/Window Context Reading)
利用现有的 `WindowsManager.cs` 底层句柄遍历，提取活跃应用的最顶层文本（GetWindowText）：
- **动态情境反馈**：通过正则或关键字解析，让宠物知道主人正在做什么。（例如检测到包含了 `"哔哩哔哩"` / `"Chrome"` 的标题栏，宠物就会触发“发呆时间过长”的监控碎碎念）。
- **进程指纹识别**：读取底层执行体名（如 `YuanShen.exe`, `Code.exe`），从而无缝切换宠物的“工作鼓励”模式或“游戏防沉迷”防线。

### 2. 生理恐慌响应机制 (Network & Hardware Reaction)
为系统注入真实硬件状态映射：
- **断网危急状态**：通过 C# `NetworkInterface.GetIsNetworkAvailable()` 监听全全局网络握手，一旦失联，宠物眼球立刻变为闪烁红光（🚨），呼出 `[NO SIGNAL]` 全息断电框。
- **系统濒死预警**：调用 `System.Diagnostics` 读取 CPU / 内存压力，一旦主频满载狂飙，宠物也同步进入“高负荷颤抖”、“瞳孔光晕散乱”的拟物热衰竭状态，和主人的设备共生共毁。

## 二、 全息物理交互突破 (Holographic Physicality)

### 1. 回收站黑洞投喂 (Drag & Drop File Devourer)
- 支持使用鼠标将真实的硬盘文件系统对象直接拖拽至宠物体表释放。
- 联动 `SHFileOperation` 的软删除与安全销毁 API，宠物在视觉上模拟将光碟吞噬的过程后，顺便把废弃文件真实扔入 Windows 的系统回收站。

### 2. HUD 全息时空系统 (Holographic Chrono HUD)
- 在宠物正上方开启一片带有动态扫描线（Scanlines）和微弱辉波泛光的独立全息图层组件。
- 它并不遵循规整的正交矩阵，而是挂载于宠物的数学物理引擎之上，随着宠物的加速猛冲或下坠产生惯性拖尾和数字漂移。

### 3. 环境潜匿变色龙 (Chameleon Mimicry)
- 借由 `GetPixel` 捕捉宠物当前足底触及环境窗口的最表盘颜色。
- 动态替换自身或瞳孔主色调进行相对应隐身，实现纯粹赛博赛朋克风韵的光学迷彩隐匿潜行。
