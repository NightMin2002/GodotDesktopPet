# 数据日志系统

> 装置终端 Tab 3。宠物监控操作员行为并自动生成报告，附带轻量操作员备忘功能。

---

## 一、系统定位

- **核心功能**：宠物自动采集键鼠输入和窗口使用数据，生成结构化行为报告
- **附属功能**：操作员手动备忘 (简易笔记，无完成状态/提醒)
- **与待办的区别**：没有 `done` 状态，没有提醒，没有进度条。共享 `SettingsManager` 持久化层但用不同存储节点

### 命名

| 层级 | 名称 | 说明 |
|------|------|------|
| Tab 标题 | 数据日志 | 装置终端第 4 个 Tab (索引 3) |
| 宠物分区 | 机体记录 | 宠物自动采集生成的行为报告 |
| 用户分区 | 操作员备忘 | 用户手动创建的笔记 |

## 二、数据模型

### 单条日志结构

```gdscript
{
    "id": "1715760000_12345",       # unix时间戳_随机数
    "title": "标题",
    "content": "正文内容",           # 纯文本
    "tags": ["sys:input", "auto"],  # 系统标签 (sys:input / sys:window / auto)
    "source": "pet",               # "user" = 操作员备忘 / "pet" = 机体记录
    "created": "2026-05-15 08:30",
    "updated": "2026-05-15 09:00",
    # 以下字段仅 sys:input 报告
    "input_data": {},              # 累积数据 (keys/combos/mouse/session_sec/total_keystrokes)
    "input_data_raw": {},          # 最后一次 C# 快照原始值 (用于跨会话增量计算)
    "input_delta": {},             # 本次合并的增量 (UI 绿字)
    "merge_count": 3,              # 当天叠加次数
    # 以下字段仅 sys:window 报告
    "window_data": {},             # 累积数据 (进程名 → {focus_sec, titles, last_active})
    "window_data_raw": {},         # 最后一次 C# 快照原始值
    "window_delta": {},            # 本次合并的增量
}
```

### 存储

`SettingsManager` 持久化到 `user://settings.cfg` 的 `[datalogs]` 节点。`get_datalogs()` / `save_datalogs()` 整个数组读写。

## 三、数据采集 (C# 层)

### InputMonitor.cs

全局键鼠输入 + 窗口追踪监控器，由 `main.gd._setup_input_monitor()` 启动。

| 采集项 | 方式 | 数据键 |
|--------|------|--------|
| 键盘按键 | `WH_KEYBOARD_LL` 低级钩子 | `keys` (每键计数) |
| 组合键 | Ctrl/Alt/Shift 修饰状态 + 非修饰键 | `combos` (如 `Ctrl+C: 42`) |
| 鼠标点击 | `GetAsyncKeyState` 50ms 轮询 | `mouse.left_clicks` / `right_clicks` / `middle_clicks` |
| 鼠标移动 | `GetCursorPos` 欧几里得距离累积 | `mouse.distance_px` |
| 前台窗口 | `GetForegroundWindow` 5s 轮询 | 进程名 → `{focus_sec, titles[], first_seen, last_active}` |

### 报告生成 (main.gd)

**当天叠加模式**：同一天的同类型报告自动合并，不会每次生成新条目。

- `_save_input_report()` — 键鼠报告写入 `source: "pet"`, `tags: ["sys:input", "auto"]`
- `_save_window_report()` — 窗口报告写入 `source: "pet"`, `tags: ["sys:window", "auto"]`
- `save_exit_reports()` — 退出时自动归档 (farewell_manager 调用)

**跨会话安全累积**：通过 `input_data_raw` 存储上次 C# 原始快照，新快照与旧原始值做差得到本次增量 (`_raw_delta`)，再加到累积数据上。C# 重启时新值 < 旧原始值则视新值本身为增量。

**增量计算 (UI 绿字)**：`_diff_input()` / `_diff_window()` 计算本次合并前后的差值，存入 `input_delta` / `window_delta`，供详情面板渲染绿色增量标注。

## 五、机体记录分区

### 两级导航

```
SYSTEM // 机体数据分类  (分类首页)
├── [//] 键鼠行为     击键统计 / 组合键 / 点击 / 移动距离    → sys:input 子列表
├── [[] 窗口程序     前台应用使用时长分布                  → sys:window 子列表
└── 更多数据源开发中...
```

点击分类卡片进入子列表 → 搜索筛选 + "生成报告"按钮 + 日志列表。左上角 `<` 返回分类首页。

### 输入报告详情

详情面板使用 RichTextLabel BBCode 渲染，三栏布局：
- **头部**：标题 + 会话时长 + 总击键
- **左栏**：按键统计 (全量，按频次降序)
- **中栏**：组合键统计 (Ctrl+C, Ctrl+V 等)
- **右栏**：鼠标统计 (左/右/中键 + 移动距离)

增量数据用绿色 `[color=#4cf06a]` BBCode 标注。

底部"键鼠全图"按钮打开独立热力图面板。

### 键鼠热力全图面板

独立 CanvasLayer (layer=100)，使用 `overlay_rects` 精确区域穿透 (面板可交互，面板外穿透到桌面)。

布局区域：
- **SYS_FUNC**：功能键行 (Esc, F1~F12)
- **ALPHA_MATRIX**：主键位矩阵 (数字行 + QWERTY + 修饰键行)
- **MOD_CTRL**：指令修饰层 (Ctrl, Win, Alt, Space)
- **NAV**：导航阵列 (Ins/Home/PgUp + Del/End/PgDn + 方向键)
- **NUMPAD**：数值输入 (小键盘 4x5 标准布局)
- **IO_DEVICE**：定位装置 (鼠标三键独立热力渲染 + 移动距离)

双模式切换：绝对值 / 基准偏差 (低于均值偏蓝，高于均值偏橙)。

### 窗口报告详情

使用 `DatalogWindowCards` 渲染卡片网格，每个应用一张卡片，显示进程名、前台时长、窗口标题列表。带目标锁定准星和雷达标尺动效。增量用绿字标注新增应用和时长变化。

## 六、操作员备忘分区

平铺列表，支持新建/编辑/删除/搜索。

- **新建**：标题默认 "备忘 MM-DD HH:MM"，全选聚焦
- **编辑**：标题+正文可编辑，防抖自动保存 (0.6s)，底部 "已保存" 徽章 (1.5s 恢复)
- **删除**：二次确认 (3 秒超时自动恢复)
- **搜索**：0.3s 防抖，匹配标题+内容+标签
- **标签**：胶囊徽章，回车新建，x 删除
- **空状态**："暂无备忘记录 / 点击 [+ 新建] 开始记录"
