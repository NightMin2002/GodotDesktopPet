## 修改话术检查清单

新增或修改话术时，逐条自检：

- [ ] 自称用「本机」或省略主语？
- [ ] 不用「主人」，不叫昵称？
- [ ] 不用 emoji？
- [ ] 关心是否用技术/客观语气包装？
- [ ] 没有直说「想你/爱你/担心你」？
- [ ] 没有撒娇或卖萌？
- [ ] 选词是否用最简自然表达（不堆术语、不用俚语）？
- [ ] 傲娇露馅频率是否克制（非关键场景不要转折）？
