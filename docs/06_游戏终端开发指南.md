# 游戏终端开发指南

> 本文档描述 `ui/game_terminal/` 模块化插件架构的开发流程。
> 旧版 `games/` 扩展包系统文档见 `06_游戏扩展系统_已冻结.md`（代码已冻结，仅供参考）。

## 架构概览

```
ui/game_terminal/
    game_terminal.gd           <- 面板骨架 (CanvasLayer)
    terminal_game_base.gd      <- 游戏基类 (TerminalGameBase)
    terminal_game_icon.gd      <- 图标基类 (TerminalGameIcon)
    theme/
        styles.gd              <- 主题代理管理器 (GameTerminalStyles)
        terminal_theme_base.gd <- 主题基类 (TerminalThemeBase)
        game_theme_override.gd <- 游戏专属主题覆写基类 (GameThemeOverride)
        theme_minimal.gd       <- 极简科幻风格主题
        theme_retro.gd         <- 街机像素风格主题
        frame_minimal.gd       <- 极简机甲边框渲染器
        frame_retro.gd         <- 街机 CRT 边框渲染器
    games/                     <- 游戏插件目录 (自动发现，零入侵)
        _theme_template.gd     <- 游戏专属主题模板 (复制到 games/xxx/theme.gd)
        ttt/
            game.gd            <- extends TerminalGameBase
            icon.gd            <- extends TerminalGameIcon
        gomoku/
            game.gd
            icon.gd
            theme.gd           <- (可选) extends GameThemeOverride
        minesweeper/
        2048/
        snake/
        tetris/
```

**核心原则**: 新增游戏只需在 `games/` 下创建文件夹，放入 `game.gd` + `icon.gd`，不需要修改骨架任何代码。

## 新增游戏步骤

### 1. 创建目录

```
games/my_game/
    game.gd    <- 必须
    icon.gd    <- 必须
    theme.gd   <- 可选 (游戏专属主题覆写)
```

### 2. game.gd 模板

```gdscript
extends TerminalGameBase

# -- 元数据 (必须覆写) --
func get_game_id() -> String: return "my_game"
func get_game_name() -> String: return "显示名称"
func get_game_desc() -> String: return "一句话描述"
func supports_auto_play() -> bool: return false

# -- 生命周期 --
func build() -> void:
    mouse_filter = Control.MOUSE_FILTER_STOP
    set_anchors_preset(Control.PRESET_FULL_RECT)
    # 构建游戏 UI...
    start_game()

func start_game() -> void:
    # 初始化/重开一局
    game_started.emit()

# -- HUD 自绘 (在 _draw 中自行绘制) --
# 骨架不再提供通用 HUD 栏，各游戏在 _draw() 中自行绘制
# 正方形游戏: 利用网格上方 header_h 区域画 HUD
# 非正方形游戏(如俄罗斯方块): 利用左右侧栏空间画 HUD

# -- AI 自玩 (supports_auto_play=true 时需实现) --
func auto_play_step() -> void:
    pass

# -- 结算 --
# 游戏结束时调用: game_over.emit(0)  # 0=胜, 1=负, 2=平
# 结算覆盖层用工厂:
# var d = GameTerminalStyles.create_result_overlay("再来一局", start_game)
```

### 3. icon.gd 模板

```gdscript
extends TerminalGameIcon

func _draw() -> void:
    var w = size.x
    var h = size.y
    var a = alphas()  # [base_alpha, highlight_alpha] 基于 hover 状态

    # 用 draw_line / draw_arc / draw_rect 等绘制动态图标
    # 可用: hue(), line_color(), accent_color(), _time, _hovered
    draw_line(Vector2(w*0.2, h*0.5), Vector2(w*0.8, h*0.5), line_color(), 1.5)
```

### 4. 完成

启动游戏，骨架 `_scan_games()` 自动发现并注册到大厅。

## TerminalGameBase 接口

| 方法 | 类型 | 说明 |
|------|------|------|
| `get_game_id()` | 必须覆写 | 唯一标识 (用于战绩 key、文件夹名) |
| `get_game_name()` | 必须覆写 | 大厅显示名称 |
| `get_game_desc()` | 必须覆写 | 大厅简短描述 |
| `supports_auto_play()` | 必须覆写 | 是否支持 AI 自玩 |
| `build()` | 必须覆写 | 构建 UI 并启动首局 |
| `start_game()` | 必须覆写 | 开始/重开一局 |
| `get_hud_data()` | 已废弃 | 骨架不再轮询，各游戏在 _draw() 中自绘 HUD |
| `get_best_score()` | 可选覆写 | 最佳分数 (骨架持久化) |
| `auto_play_step()` | 可选覆写 | AI 每步操作 (骨架 Timer 驱动) |

**信号:**
- `game_started` -- 新局开始时发出
- `game_over(result: int)` -- 游戏结束时发出 (0=胜, 1=负, 2=平)

## TerminalGameIcon 接口

| 成员 | 说明 |
|------|------|
| `game_id: String` | 骨架设置，可读取 |
| `_hovered: bool` | 骨架驱动的悬停状态 |
| `_time: float` | 内部时钟 (自动累加) |
| `hue() -> float` | 当前 UI 主题色相 |
| `alphas() -> Array` | `[base, highlight]` 透明度 (基于 hover) |
| `line_color() -> Color` | 主题色线条颜色 |
| `accent_color() -> Color` | 主题色强调颜色 |

子类只需覆写 `_draw()` 绘制图标，`_process` 和 `queue_redraw()` 已由基类处理。

## 主题系统

### 三层架构

```
查询优先级: 游戏覆写层 > 当前终端主题 > 基类默认值

GameTerminalStyles (代理入口)
    |
    ├── GameThemeOverride (游戏专属覆写层，可选)
    |       返回非 null → 使用覆写值
    |       返回 null   → 回退到终端主题
    |
    └── TerminalThemeBase (终端主题)
            ├── theme_minimal.gd (极简科幻)
            └── theme_retro.gd  (街机像素)
```

### GameTerminalStyles 代理方法

游戏代码只需调用 `GameTerminalStyles.xxx()`，自动适配主题切换和游戏覆写。

**色值 (经过覆写层):**

| 方法 | 用途 |
|------|------|
| `accent()` | 主题强调色 (活跃状态、选中指示等) |
| `dim()` | 低亮度色 (次要文本、描述) |
| `bright()` | 高亮色 (标题、重点文字) |
| `bg_deep()` | 深色背景 |
| `border_base()` | 边框基色 |
| `status_active()` | 就绪/胜利状态色 (绿色系) |
| `status_warning()` | 警告状态色 (琥珀色) |

**扩展色值 (骨架专用，不经覆写层):**

| 方法 | 用途 |
|------|------|
| `status_danger()` | 败北/危险色 (红色系) |
| `hint_color()` | 极淡提示色 (操作说明、游戏计数) |
| `footer_btn_color()` | 底栏按钮文字色 |
| `footer_btn_hover_color()` | 底栏按钮悬浮文字色 |

**StyleBox:**

| 方法 | 用途 |
|------|------|
| `separator_style()` | 水平/垂直分隔线 |
| `content_area_bg()` | 主内容区背景 |
| `status_bar_bg()` | 底部状态栏背景 |
| `small_btn_normal/hover()` | 通用小按钮 |
| `preview_panel_bg()` | 大厅右侧预览面板 |
| `list_item_normal/selected()` | 大厅列表条目 |
| `lobby_btn_normal/hover()` | 大厅操作按钮 |
| `footer_btn_normal/hover()` | 底栏按钮 |

**工具方法:**

| 方法 | 用途 |
|------|------|
| `dim_label(text, size)` | 创建低亮度标签 |
| `make_label(text, size, color)` | 创建指定颜色标签 |
| `add_tech_brackets(control, size, offset)` | 四角科技感包边 |
| `create_result_overlay(btn_text, callback)` | 结算覆盖层工厂 |
| `show_result_overlay(overlay, label, text, color)` | 显示结算结果 |
| `game_override()` | 获取当前游戏的覆写实例 |

### 游戏专属主题 (GameThemeOverride)

当游戏需要自定义配色时，在游戏目录下放一个 `theme.gd`:

```gdscript
extends GameThemeOverride

# 覆写终端通用色值 (返回 null = 回退到终端主题)
func accent() -> Variant:
    return Color(0.2, 0.8, 0.6)  # 自定义强调色

func dim() -> Variant:
    return null  # 不覆写，走终端全局主题

# 定义游戏专属扩展色值 (终端主题里没有的)
func grid_color() -> Color:
    return Color(0.3, 0.4, 0.5, 0.4)

func piece_color_p1() -> Color:
    return Color.WHITE
```

**生命周期 (骨架自动管理):**
1. `_scan_games()` 自动探测 `theme.gd` 存入注册表
2. `_launch_terminal_game()` 在 `build()` 前自动 `push`
3. `_cleanup_active_game()` 退出时自动 `pop`

**在游戏中访问专属扩展色值:**

```gdscript
var ov = GameTerminalStyles.game_override()
if ov and ov.has_method("grid_color"):
    var c = ov.grid_color()
```

                     ^                  |

## 大厅布局

主从布局 (Master-Detail):
- 左侧: 可滚动游戏列表，悬浮即选中
- 右侧: 预览面板 (大号图标 + 名称/描述/战绩 + 启动/委托按钮)
- 点击列表项或右侧"启动推演"按钮启动游戏

## 开发规范

### 渲染方式

终端游戏支持两种渲染:
- **Canvas `_draw()` 自绘** -- 井字棋、贪吃蛇、俄罗斯方块使用
- **Godot Control 节点树** -- 扫雷、2048 使用

两种方式在全息屏投影中效果一致。

### 话术系统

洗牌防重复模式:

```gdscript
const _POOL_XXX := ["台词1", "台词2", ...]
var _q_xxx: Array = []

# 从队列取一条 (空了就重填+洗牌)
func _pick(queue: Array, pool: Array) -> String:
    if queue.is_empty():
        queue.append_array(pool)
        queue.shuffle()
    return queue.pop_back()
```

### 结算覆盖层

使用 `GameTerminalStyles.create_result_overlay()` 工厂统一创建:

```gdscript
func _build_result_overlay() -> void:
    var d = GameTerminalStyles.create_result_overlay("再来一局", start_game)
    _result_overlay = d.overlay
    _result_label = d.label
    add_child(_result_overlay)

func _show_result(text: String, color: Color) -> void:
    GameTerminalStyles.show_result_overlay(_result_overlay, _result_label, text, color)
```

### 输入处理

- 通过 `gui_input` 信号连接 (Control 节点方式)
- 方向键 + WASD 建议使用 `physical_keycode` 绕过输入法

### 注意事项

1. `build()` 在节点入树后被调用 -- `grab_focus()` 等操作安全
2. 布局锚点由骨架预设为 `PRESET_FULL_RECT` -- `build()` 中可以重设但通常不需要
3. `game_over.emit()` 必须传入 result (0/1/2) -- 骨架据此更新战绩
4. HUD 由游戏自己在 `_draw()` 中绘制 -- 骨架不提供通用 HUD 栏，布局自治
5. 游戏专属主题 `theme.gd` 在 `build()` 调用前已 push -- `build()` 中读取的色值已经是覆写后的
