# 游戏扩展系统

## 系统架构

游戏以扩展包形式存在，运行时通过 SubViewport 渲染，自动映射到宠物全息迷你屏。

```
GameManager (CanvasLayer)
    ├── SubViewportContainer    ← 屏幕上的游戏面板
    │   └── SubViewport         ← 游戏 UI 渲染目标
    │       └── [游戏面板]       ← 由 game.gd 构建的 UI 树
    ├── 悬浮组件 (解构式 UI)    ← BaseGame 统一管理
    │   ├── 标题气泡             ← 面板上方悬浮
    │   ├── 连接线               ← 标题→面板
    │   ├── 侧边按钮组 (i + ✕)   ← 面板外侧悬浮
    │   └── 重开按钮             ← 面板下方悬浮 (game over 后)
    ├── 全息合成视口 (SubViewport) ← 合成面板+悬浮组件的完整画面
    │   ├── TextureRect         ← 实时镜像游戏面板
    │   └── 悬浮组件克隆体       ← duplicate(0) 纯视觉副本
    └── 信号驱动
        ├── pet_gaming_changed  → PetGaming (宠物锁定/踏板/全息屏)
        └── close_game_requested → GameManager (清理)
```

### 数据流

1. `GameManager.launch_game()` → 创建 SubViewport + 实例化游戏脚本
2. 游戏脚本 `start()` → 在 SubViewport 内构建 UI + 创建悬浮组件 + 创建全息合成视口
3. `PetGaming` 每帧取全息合成视口纹理 → 梯形透视渲染到宠物侧面
4. 游戏结束 → `game_finished` 信号 → 悬浮重开按钮弹出
5. 关闭 → `close_game_requested` → `GameManager.close_game()` → 清理一切

### 渲染通用性

SubViewport 系统对游戏内部渲染方式**完全无感知**，已验证两种方案:

| 渲染方式 | 验证游戏 | 全息屏效果 |
|----------|---------|-----------|
| Canvas `_draw()` 自绘 | 井字棋 | 正常 |
| Godot Control 节点树 | 扫雷 | 正常 |

任何能在 SubViewport 内渲染的内容都会自动出现在全息屏上，无需额外适配。

## BaseGame 接口

```gdscript
class_name BaseGame extends RefCounted

enum Result { WIN, LOSE, DRAW }
signal game_finished(result: Result)

# GameManager 自动注入
var game_viewport: SubViewport
var game_container: SubViewportContainer
var screen_size: Vector2
var _pet: Node2D

# 子类必须实现
func get_game_id() -> String
func get_game_name() -> String
func get_game_desc() -> String
func start() -> void       # 构建 UI + 初始化
func cleanup() -> void     # 清理节点 + 断开信号
```

## 新游戏开发指南

### 1. 创建目录

```
games/
└── my_game/
    ├── meta.json     ← 必须
    └── game.gd       ← 必须, extends BaseGame
```

### 2. meta.json 格式

```json
{
    "id": "my_game",
    "name": "显示名称",
    "desc": "一句话描述",
    "version": "1.0.0",
    "author": "作者",
    "script": "res://games/my_game/game.gd"
}
```

### 3. game.gd 标准模板

    pass

    # 清理所有 UI 节点
    super.cleanup()  # 必须调用, 清理悬浮组件 + 教程面板 + 全息视口

### 4. 面板通用规范

游戏面板采用**解构式悬浮布局** — 标题、按钮、重开全部独立于面板外部悬浮，由 BaseGame 统一管理。

| 规范 | 说明 |
|------|------|
| 面板背景 | `Color(0.04, 0.06, 0.12, 0.95)` + 主题色 1px 边框 + 12px 圆角 |
| 标题气泡 | 悬浮在面板上方, pill 形状, 主题色文字, 支持拖拽带动面板 |
| 侧边按钮 | 面板外侧悬浮圆形按钮 (i + ✕), 方向感知远离宠物 |
| 连接线 | 1px 主题色细线, 标题底部→面板顶部 |
| 发言区 | 深蓝底 + 左侧 2px 主题色竖线, 13px 字号, autowrap |
| 战绩标签 | RichTextLabel + BBCode 彩色 |
| 再来一局 | 结束后悬浮在面板下方, pill 形状, 面板尺寸不跳动 |
| 弹入动画 | 分层入场: 面板先弹入 → 标题 0.12s 延迟浮上 → 按钮逐个弹出 |
| 弹出动画 | `modulate.a: 1→0 (0.15s)` + `scale: 1→0.5 (0.15s)` |
| 定位 | 宠物侧面, 间距自适应, clamp 不超屏 |
| 空间保护 | 重开按钮出现时自动上移面板确保可见 |

### 5. 任务简报面板 (可选)

BaseGame 内置简报系统，游戏按需接入:

```gdscript
# 覆写: 返回简报步骤 (空数组 = 不显示 "i" 按钮)
func get_tutorial_steps() -> Array[Dictionary]:
    return [
        {"text": "左键点击格子 → 揭开该区域"},
        {"text": "数字 = 周围威胁源数量"},
    ]

# 覆写 (可选): 返回预览动画 Control 节点, 显示在简报面板顶部
func get_tutorial_preview() -> Control:
    return null
```

| 设计要点 | 说明 |
|---------|------|
| 概念 | "任务简报" — 宠物用冷淡口吻给你做游戏说明，符合 kuudere 人设 |
| 按钮 | 侧边悬浮 "i" 圆形按钮，有教程内容时自动创建 |
| 渲染层 | 添加到 CanvasLayer，不进 SubViewport，不显示在全息屏上 |
| 定位 | 游戏面板远离宠物一侧，避让侧边按钮，顶部对齐，边界保护 |
| 拖拽跟随 | 游戏面板拖拽时自动同步简报面板位置 |
| 动画 | 弹入 (scale 0.85→1 + fade)，弹出 (scale→0.9 + fade) |
| cleanup | 子类 `cleanup()` 末尾必须调用 `super.cleanup()` |

### 6. 话术系统

洗牌防重复模式:

```gdscript
const _POOL_XXX := ["话术1", "话术2", ...]
var _q_xxx: Array = []

func _pick(queue: Array, pool: Array) -> String:
    if queue.is_empty():
        queue.append_array(pool)
        queue.shuffle()
    return queue.pop_back()
```

话术通过面板内 `_status_label` 显示 (不走全局气泡), 淡入高亮动画:

```gdscript
func _say(text: String) -> void:
    _status_label.text = text
    _speech_panel.modulate = Color(1.4, 1.4, 1.4, 1.0)
    var tween = game_viewport.create_tween()
    tween.tween_property(_speech_panel, "modulate", Color.WHITE, 0.5)
```

中途关闭时的话术通过宠物气泡显示 (面板即将关闭, `_say` 看不到):

```gdscript
if is_instance_valid(_pet) and _pet.has_method("show_local_bubble"):
    _pet.show_local_bubble("吐槽文字")
```

## 宠物游戏态 (PetGaming)

全部逻辑封装在 `entities/pet/pet_gaming.gd` (RefCounted), 通过 `pet_gaming_changed` 信号驱动:

| 行为 | 实现 |
|------|------|
| 锁定不动 | 高阻尼 (`linear_damp=20`) + 每帧清零速度 |
| 状态保护 | `transition_to()` 阻止非 idle/fall 跳转, `idle.process()` 跳过所有转换 |
| 瞳孔注视 | 每帧强制 `forced_look_dir` 指向全息屏方向 |
| 全息迷你屏 | 合成视口纹理梯形透视渲染 (近端收缩 15%), 动态宽高比 |
| 悬浮踏板 | 脚下生成 StaticBody2D 单向踏板, 缓升 15px, 淡入淡出 |
| 微行为屏蔽 | 游戏态跳过所有微行为, 保留深夜时钟检测 |
| 空间跳跃保护 | 启动时取消进行中的 roam, 退出时设置 60 秒冷却 |
| 游戏结束 | 切 fall 状态自然过渡 |
