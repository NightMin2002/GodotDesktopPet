# 游戏扩展系统

## 系统架构

游戏以扩展包形式存在，运行时通过 SubViewport 渲染，自动映射到宠物全息迷你屏。

```
GameManager (CanvasLayer)
    +-- SubViewportContainer    <- 屏幕上的游戏面板
    |   +-- SubViewport         <- 游戏 UI 渲染目标
    |       +-- [游戏面板]       <- 由 game.gd 构建的 UI 树
    +-- 悬浮组件 (解构式 UI)    <- BaseGame 统一管理
    |   +-- 标题气泡             <- 面板上方悬浮
    |   +-- 连接线               <- 标题->面板
    |   +-- 侧边按钮组 (i + x)   <- 面板外侧悬浮
    |   +-- 发言气泡             <- 侧边按钮对面悬浮 (带小三角指向面板)
    |   +-- 重开按钮             <- 面板下方悬浮 (game over 后)
    +-- 全息合成视口 (SubViewport) <- 合成面板+悬浮组件的完整画面
    |   +-- TextureRect         <- 实时镜像游戏面板
    |   +-- 悬浮组件克隆体       <- duplicate(0) 纯视觉副本
    +-- 信号驱动
        +-- pet_gaming_changed  -> PetGaming (宠物锁定/踏板/全息屏)
        +-- close_game_requested -> GameManager (清理)
```

### 数据流

1. `GameManager.launch_game()` -> 创建 SubViewport + 实例化游戏脚本
2. 游戏脚本 `start()` -> 在 SubViewport 内构建 UI + `_say()` 初始话术 (暂存到 `_pending_speech`)
3. `_setup_floating_chrome()` -> 创建悬浮组件 (标题/按钮/发言气泡/重开) + 刷出暂存话术
4. `await process_frame` -> 定位 -> 全息视口 -> 入场动画 (严格顺序, 保证全息布局基于正确位置)
5. `PetGaming` 每帧取全息合成视口纹理 -> 梯形透视渲染到宠物侧面
6. 游戏结束 -> `game_finished` 信号 -> 悬浮重开按钮弹出
7. 关闭 -> `close_game_requested` -> `GameManager.close_game()` -> 清理一切

### 渲染通用性

SubViewport 系统对游戏内部渲染方式**完全无感知**，已验证两种方案:

| 渲染方式 | 验证游戏 | 全息屏效果 |
|----------|---------|-----------|
| Canvas `_draw()` 自绘 | 井字棋 | 正常 |
| Godot Control 节点树 | 扫雷 | 正常 |

任何能在 SubViewport 内渲染的内容都会自动出现在全息屏上，无需额外适配。

## BaseGame 接口

```gdscript
class_name BaseGame extends RefCounted

enum Result { WIN, LOSE, DRAW }
signal game_finished(result: Result)

# GameManager 自动注入
var game_viewport: SubViewport
var game_container: SubViewportContainer
var screen_size: Vector2
var _pet: Node2D

# 通用状态 (子类直接读写)
var _wins: int = 0
var _losses: int = 0
var _game_over: bool = false
var _compare_label: Label = null        # 双方成绩对比行

# 子类必须实现
func get_game_id() -> String
func get_game_name() -> String
func get_game_desc() -> String
func start() -> void       # 构建 UI + 初始化
func cleanup() -> void     # 清理节点 + 断开信号

# 子类可覆写 (均有默认实现)
func get_default_panel_size() -> Vector2    # 定位用 fallback 尺寸, 默认 (280, 400)
func _on_restart() -> void                  # 重开游戏逻辑

# ── 模板方法 Hook: 中途关闭 ──
# BaseGame._on_close_cleanup() 统一处理关闭流程, 子类通过以下 hook 插入差异:
func _on_close_extra_cleanup() -> void      # 额外清理 (如停计时器、保存特殊数据)
func get_close_speech_pool() -> Array       # 中途关闭话术池 (随机抽取)
func get_close_speech() -> String           # 中途关闭单句话术 (pool 优先)
func get_auto_close_lines() -> Array        # 自玩被关闭时的话术

# ── 模板方法 Hook: 自玩启动 ──
# BaseGame._start_auto_play() 统一处理自玩启动流程, 子类通过以下 hook 插入差异:
func get_auto_start_lines() -> Array        # 自玩启动话术
func get_auto_play_interval() -> float      # 自玩定时器间隔 (秒)
func _on_auto_play_started() -> void        # 自玩启动后的额外初始化
func _get_takeover_lines() -> Array         # 用户接管时的台词

# BaseGame 统一提供 (子类直接调用)
func _say(text)                             # 悬浮发言气泡 (自玩时自动静默)
func _pick(queue, pool) -> String           # 洗牌防重复话术抽取
func _mount_panel(panel)                    # 挂载面板 + 定位 + 弹入动画 + 悬浮组件
func _create_game_panel_bg() -> StyleBoxFlat # 标准面板背景工厂
func _create_panel_skeleton(w, margins) -> Dictionary  # 面板骨架 {panel, vbox}
func _create_compare_row(parent, text) -> Label        # 双方对比行工厂
func _create_score_rich_label() -> RichTextLabel       # 战绩 BBCode 标签工厂
func _load_scores() / _save_scores()        # 战绩持久化 (SettingsManager)
func _score_key(suffix) -> String           # 自玩/手动分离的存储 key
func _other_score_key(suffix) -> String     # 对方数据的存储 key
func _show_restart_bubble()                 # 显示重开按钮
func _hide_restart_bubble()                 # 隐藏重开按钮
func _close_game()                          # 退场动画 + 关闭信号
func _clamp_panel_to_screen()               # 面板边界保护
func sync_viewport_size()                   # 同步 SubViewport 大小

# 自玩基础设施 (子类实现 AI 时使用)
var _auto_play: bool                        # 自玩模式标记 (GameManager 在 start() 前设置)
var _auto_timer: Timer                      # 自玩步骤定时器
const AUTO_PLAY_ALPHA                       # 自玩面板透明度 (0.6)
func _auto_fade(alpha, dur)                 # 淡入/淡出面板 + 所有悬浮组件
func _auto_create_timer(interval)           # 创建定时器 → _auto_play_step()
func _auto_destroy_timer()                  # 销毁定时器
func _auto_play_step()                      # AI 步骤 (子类覆写)
func _stop_auto_play()                      # 用户接管: 恢复气泡 + 面板 + 台词 (通用)
func _auto_finish_and_close()               # 游戏结束 → 等 3s → 自动关闭
func _show_xp_popup(amount)                 # XP 飘字动画 (面板底部)
```

**自玩行为:**
- `_say()` 自动静默 (不自言自语)
- 发言气泡在 `_setup_chrome` 时隐藏
- 用户接管时 `_stop_auto_play()` 恢复气泡
- 自玩启动/关闭/接管的话术均通过 hook 方法提供，不再在子类中写流程代码

**战绩数据分离:**
- 存储 key 通过 `_score_key()` 自动区分: `game_{id}_wins` (用户) vs `game_{id}_auto_wins` (宠物)
- `_other_score_key()` 读取对方数据, 用于面板对比行
- 各游戏跟踪的指标:

| 游戏 | 指标 | 存储 key |
|------|------|----------|
| 2048 | 最高分, 最高块 | `best`, `best_tile` |
| 贪吃蛇 | 最长长度, 局数 | `best_len`, `games` |
| 扫雷 | 通关数, 触雷数 | `wins`, `losses` |
| 井字棋 | 胜, 负, 平 | `wins`, `losses`, `draws` |
| 俄罗斯方块 | 最高分, 总消行, 局数 | `best`, `lines`, `games` |

## 新游戏开发指南

### 1. 创建目录

```
games/
└── my_game/

    └── game.gd       ← 必须, extends BaseGame
```

### 2. meta.json 格式

```json

    "id": "my_game",
    "name": "显示名称",
    "desc": "一句话描述",
    "version": "1.0.0",
    "author": "作者",
    "script": "res://games/my_game/game.gd"

```

### 3. game.gd 标准模板

```gdscript
extends BaseGame

# ── 元数据 ──
func get_game_id() -> String: return "my_game"
func get_game_name() -> String: return "显示名称"
func get_game_desc() -> String: return "一句话描述"
func get_default_panel_size() -> Vector2: return Vector2(280, 400)

# ── 话术 Hook ──
func get_close_speech_pool() -> Array:
    return ["中断。...这算你放弃。"]

func get_auto_close_lines() -> Array:
    return ["...？", "...中断。"]

func get_auto_start_lines() -> Array:
    return ["自主训练启动。", "...自检模式。"]

func get_auto_play_interval() -> float:
    return 0.4

func _get_takeover_lines() -> Array:
    return ["...你来？好。", "操作权移交。"]

# ── 生命周期 ──
func start() -> void:
    _load_scores()
    _build_ui()
    _say("初始话术")  # 可在 _mount_panel 之前调用, 自动暂存

func _build_ui() -> void:
    var skel = _create_panel_skeleton(280)  # 一行创建面板 + MarginContainer + VBoxContainer
    _panel = skel.panel
    var vbox = skel.vbox

    # ... 构建游戏 UI, 加入 vbox ...

    # 双方对比行 (工厂方法, 自动挂载到 _compare_label)
    _create_compare_row(vbox, "操作员: 0 | 本机: 0")

    # 战绩标签 (工厂方法)
    _score_label = _create_score_rich_label()
    vbox.add_child(_score_label)

    await _mount_panel(_panel)  # 一行搞定: 挂载 + 定位 + 弹入动画 + 悬浮组件

func _on_restart() -> void:
    # 重置游戏状态
    pass

func _on_close_extra_cleanup() -> void:
    # 中途关闭时的额外清理 (可选)
    pass

func cleanup() -> void:
    if is_instance_valid(_panel):
        _panel.queue_free()
    _panel = null
    super.cleanup()  # 必须调用, 清理悬浮组件 + 教程面板 + 全息视口
```

### 4. 面板通用规范

游戏面板采用**解构式悬浮布局** — 标题、按钮、发言、重开全部独立于面板外部悬浮，由 BaseGame 统一管理。子类只需构建面板内容，调用 `_mount_panel()` 即可自动完成挂载、定位、弹入动画、悬浮组件创建。

面板背景使用 `_create_game_panel_bg()` 工厂方法创建统一风格（深色半透明 + 主题色 1px 边框 + 12px 圆角）。

| 规范 | 说明 |
|------|------|
| 面板背景 | `Color(0.04, 0.06, 0.12, 0.95)` + 主题色 1px 边框 + 12px 圆角 |
| 标题气泡 | 悬浮在面板上方, pill 形状, 主题色文字, 支持拖拽带动面板 |
| 侧边按钮 | 面板外侧悬浮圆形按钮 (i + x), 方向感知远离宠物 |
| 连接线 | 1px 主题色细线, 标题底部->面板顶部 |
| 发言气泡 | 面板侧面悬浮 (侧边按钮对面, 靠近宠物), 带小三角箭头指向面板 |
| 战绩标签 | RichTextLabel + BBCode 彩色 |
| 再来一局 | 结束后悬浮在面板下方, pill 形状, 用固定常量 `_RESTART_RESERVE` 预留空间 |
| 弹入动画 | 分层入场: 面板先弹入 -> 标题 0.12s 延迟浮上 -> 按钮逐个弹出 -> 发言气泡淡入 |
| 弹出动画 | `modulate.a: 1->0 (0.15s)` + `scale: 1->0.5 (0.15s)` |
| 定位 | 宠物侧面, 避让全息迷你屏, clamp 不超屏, 底部预留重开按钮空间 |
| 空间保护 | 重开按钮空间始终预留 (非按需), 面板初始化时即预留底部空间 |
| 初始化顺序 | 定位 -> 全息视口 -> 入场动画 (全息基于正确位置创建, 避免动画干扰) |

| 设计要点 | 说明 |

| cleanup | 子类 `cleanup()` 末尾必须调用 `super.cleanup()` |

### 6. 话术系统

洗牌防重复模式:

```gdscript
const _POOL_XXX := ["话术1", "话术2", ...]
var _q_xxx: Array = []

func _pick(queue: Array, pool: Array) -> String:
    if queue.is_empty():
        queue.append_array(pool)
        queue.shuffle()
    return queue.pop_back()
```

话术通过 BaseGame 统一管理的悬浮发言气泡显示 (不走全局气泡), 带淡入高亮动画。
`_pick()` 已统一在 BaseGame 基类中提供，子类直接调用即可。

```gdscript
# BaseGame 统一提供, 子类直接调用
func _say(text: String) -> void:
    _speech_label.text = text
    # 同步全息克隆体文字
    if is_instance_valid(_holo_speech):
        ...
    # 淡入高亮
    _speech_bubble.modulate = Color(1.4, 1.4, 1.4, 1.0)
    tween.tween_property(_speech_bubble, "modulate", Color.WHITE, 0.5)
```

注意: `_say()` 可在 `start()` 中早于 `_setup_floating_chrome()` 调用, 文本会暂存到 `_pending_speech` 中, 气泡创建后自动显示。

中途关闭时的话术通过宠物气泡显示 (面板即将关闭, `_say` 看不到):

```gdscript
if is_instance_valid(_pet) and _pet.has_method("show_local_bubble"):
    _pet.show_local_bubble("吐槽文字")
```

## 自主活动调度器 (IdleActivities)

封装在 `entities/pet/idle_activities.gd` (RefCounted), 由 `pet._process()` 每帧驱动。

### 调度机制

| 模式 | 间隔 | 说明 |
|------|------|------|
| 关闭 (0) | - | 不触发任何自主活动 |
| 偶尔 (1) | 8~12 分钟 | 默认模式 |
| 频繁 (2) | 1~2 分钟 | 活跃模式 |

计时器**仅在 idle 状态且无游戏/无空间跳跃/无微行为时**累积。事件进行中计时器暂停。

### 活动池

| 活动 | 权重 | 概率 | 前置条件 |
|------|------|------|----------|
| 空间跳跃 | 3.0 | 75% | `free_roam_enabled` 开启 |
| 自玩游戏 | 1.0 | 25% | 无游戏进行中 |

## 开发注意事项

### 架构模式: 模板方法 (Template Method)

BaseGame 采用**模板方法模式** — 基类定义完整的执行流程，子类只通过覆写 hook 方法提供数据（话术、参数）。

**关键原则: 子类不写流程，只写数据和游戏逻辑。**

#### 中途关闭流程

BaseGame `_on_close_cleanup()` 已实现完整的关闭流程:

```
_on_close_cleanup():
  if not _game_over:
    _game_over = true
    _on_close_extra_cleanup()       ← hook: 子类额外清理
    _losses += 1
    _save_scores()
    game_finished.emit(LOSE)
    if was_auto:
      show_bubble(get_auto_close_lines())   ← hook: 自玩关闭话术
    else:
      show_bubble(get_close_speech_pool())  ← hook: 手动关闭话术
```

子类只需覆写 hook，**禁止覆写 `_on_close_cleanup()` 本身**。

#### 自玩启动流程

BaseGame `_start_auto_play()` 已实现完整的自玩启动流程:

```
_start_auto_play():
  _auto_play = true
  show_bubble(get_auto_start_lines())  ← hook: 启动话术
  await 0.6s
  _auto_fade(AUTO_PLAY_ALPHA)
  _on_auto_play_started()              ← hook: 额外初始化
  _auto_create_timer(get_auto_play_interval())  ← hook: 定时器间隔
```

子类只需覆写 hook，**禁止覆写 `_start_auto_play()` 本身**。

### UI 工厂方法

| 方法 | 用途 | 返回值 |
|------|------|--------|
| `_create_panel_skeleton(w, margins)` | 面板 + Margin + VBox 骨架 | `{panel, vbox}` |
| `_create_compare_row(parent, text)` | 双方成绩对比行 | Label (自动挂到 `_compare_label`) |
| `_create_score_rich_label()` | BBCode 战绩标签 | RichTextLabel |
| `_create_game_panel_bg()` | 统一面板背景 StyleBox | StyleBoxFlat |

**所有工厂方法返回的控件需自行 `add_child` 到 vbox（`_create_compare_row` 除外，已自动添加）。**

### 常见陷阱

1. **`cleanup()` 必须调用 `super.cleanup()`** — 否则悬浮组件和全息视口不会清理
2. **`_say()` 可以在 `_mount_panel()` 之前调用** — 文本会暂存，气泡创建后自动显示
3. **`_create_panel_skeleton` 的 margins 参数是可选的** — 不传则用默认值 `{left:14, right:14, top:12, bottom:6, separation:8}`
4. **井字棋的 GlitchBg 特殊处理** — 需要在骨架创建后插入 GlitchBg 并重排子节点顺序
5. **`get_auto_play_interval()` 可以返回动态值** — 如俄罗斯方块根据熟练度计算间隔
