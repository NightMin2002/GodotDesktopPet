# 宠物观察日志系统需求文档 (Pet Observation Diary System)

## 1. 系统定位与设计理念
- **核心定位**：非传统的实用类“笔记”或“待办”，而是作为增强宠物“AI人格”与陪伴感的**隐藏彩蛋系统**。
- **背景设定**：赛博机械宠物在后台静默运行，充当“人类观察者”，将用户的电脑使用行为记录为具有科技感和吐槽属性的内部日志。
- **展示方式**：深度集成在现有的“设备终端 (Device Terminal)”系统中，以 Markdown 格式呈现出类似“系统日志 / 机体诊断报告”的视觉效果。

## 2. 核心功能需求

### 2.1 行为数据采集 (数据源)
在**不侵犯用户隐私、不触发反病毒反作弊系统**的前提下，通过 C# 调用 Windows 原生 API 抓取以下三类非敏感维度的行为特征：

1. **活动窗口特征 (Active Window Tracking)**
   - **抓取内容**：当前处于焦点的窗口标题字符串（如“xxx - Visual Studio Code”、“Bilibili - Google Chrome”）。
   - **应用逻辑**：通过关键词匹配（如包含“游戏”、“IDE”、“视频网站”等），判断用户处于“开发模式”、“低俗娱乐模式”或“摸鱼模式”。

2. **键鼠活跃状态 (Input Activity/APM)**
   - **抓取内容**：获取用户最后一次输入（键盘或鼠标）的系统空闲时间（Idle Time）。**绝不记录具体按键内容**。
   - **应用逻辑**：
     - 若空闲时间过长（如 > 1小时）：判定为“进入瘫痪状态”或“离线”。
     - 若状态频繁高发且持续：判定为“机体疯狂遭受敲击/高频输出状态”。

3. **剪贴板动作频次 (Clipboard Operation Frequency)**
   - **抓取内容**：监听系统剪贴板更新事件，仅进行计数统计（Counter），不读取具体文本内容。
   - **应用逻辑**：将高频的复制粘贴行为包装为吐槽点的素材（如：“今日 Ctrl+C 触发50次，复读行为严重”）。

*(注：系统不采集电池、音频、CPU 等硬件或外设敏感数据。)*

### 2.2 观察日志生成系统 (Log Generation)
- **定时评估与触发**：系统根据预设的时间间隔（如每小时或切换关键程序时），对采集到的行为切片进行评估。
- **文案组装池**：基于读取到的特征条件（`If-Else` 或 `Match`），从预设文案池中抽取符合人设的“吐槽”或“观察记录”。
- **本地存储**：组装好的日志内容按天归档，以结构化 Markdown 文本持久化存储在特定的本地目录中（坚决不上传网络）。

### 2.3 终端日志显示层 (Terminal Display UI)
- **接入点**：在“设备终端”面板中新增一个隐藏或深层级入口（如 `> cat /var/log/human_observation.md`）。
- **Markdown 渲染引擎**：引入 Godot 社区的 Markdown 解析方案（如 `MarkdownLabel` 插件），将存储的 Markdown 文本解析转换为原生 `RichTextLabel` 支持的 BBCode 展示。
- **UI 风格**：全冷色调、代码高亮、符合终端命令行的专业与机械感。

## 3. 技术实现路线准备

为了准备后续开发，需要按以下阶段进行技术验证和实现：

### 第一阶段：底层能力基建 (C# API 封装)
在 Godot 中编写 C# 静态工具类 `OsObserverHelper.cs`，封装必要的 `user32.dll` 接口：
- `GetForegroundWindow()` + `GetWindowText()`：获取焦点窗口名称。
- `GetLastInputInfo()`：获取键鼠空闲时长。
- `AddClipboardFormatListener()`：挂载剪贴板事件监听计数器。

### 第二阶段：Markdown 渲染能力接入
- 评估并在 Godot 插件体系中引入 `MarkdownLabel`（或其他能够将 Markdown 转 BBCode 的模块）。
- 在“Device Terminal” UI 层中实装测试，确保渲染表格、代码块、列表的样式与目前高对比度的 UI 主题统一。

### 第三阶段：业务逻辑与表现层开发
- 构建 `ObservationManager` 控制节点，通过 `Timer` 拉取底层数据。
- 设计简单的关键字槽点匹配规则表（JSON格式配置）。
- 实现日志写入到本地文件（`.md` 后缀），以及终端界面的按日期分页查阅功能。
