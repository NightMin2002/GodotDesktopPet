# 🔮 Desktop Pet — 桌面机械单眼宠物
![Platform](https://img.shields.io/badge/Platform-Windows_10%2B-blue?logo=windows)

一只活在你桌面上的赛博机械生物。它能在你的应用程序窗口之间跳跃、奔跑和攀爬，完全遵循物理定律——包括重力、碰撞和弹性。

> ⚠️ **仅支持 Windows 平台**：基于 Godot 4.6 (.NET) 构建，由于其深度调用了 `Win32 API`（进行底层窗口枚举机制、任务栏穿透屏蔽等），故暂不兼容 Mac 与 Linux！

---

## ✨ 核心特性

### 🎯 物理驱动行为
- **真实物理引擎**：宠物是一个完整的 `RigidBody2D`，一切移动基于力和冲量，不存在预设动画轨迹
- **5 态状态机**：待机 → 行走 → 跳跃 → 掉落 → 拖拽，行为自然流畅
- **弹簧力拖拽**：按住宠物拖动时，它会像弹簧一样跟随鼠标弹性运动

### 👁️ 科幻视觉系统
- **纯代码渲染**：不使用任何贴图素材，全部视觉效果由数学公式实时绘制
- **智能瞳孔追踪**：眼球自动跟随鼠标移动，鼠标静止后切换为自主好奇游走
- **机械虹膜眨眼**：模拟机械快门的收缩式眨眼动画
- **全息光带拖影**：高速运动时产生 HSV 色彩空间的渐变彩色拖影
- **虹彩冲击波**：高速碰撞时爆发扩散的彩虹光环特效

### 🪟 桌面窗口交互
- **窗口感知**：通过 Win32 API 实时获取桌面所有可见窗口的位置和层叠关系
- **三种交互模式**：
  - 🌍 **自由漫游**：宠物可以自由站在任何窗口的顶部和底部边缘
  - 🔒 **窗口封闭**：宠物被困在当前所在的窗口内移动
  - 🚫 **窗口排斥**：宠物无法进入窗口区域，但可以从内部离开
- **Z-Order 遮挡裁剪**：被上层窗口遮挡的踏板区域会被精确切割，不产生错误碰撞
- **最大化窗口过滤**：自动忽略全屏/最大化窗口，避免误封锁

### ⏰ 实用功能
- **定时提醒**：设置自定义时间提醒，宠物头顶弹出金色气泡通知
- **开机自启动**：一键注册到 Windows 注册表实现开机启动
- **系统托盘常驻**：隐藏任务栏图标，在系统托盘安静运行
- **设置持久化**：所有偏好设置跨重启保存

## 🚀 快速开始

### 📥 玩家下载 (免配置直接玩)

请前往本仓库右侧的 **[Releases 页面](../../releases)** 下载最新版本的 `Setup.exe` 安装包。
> *注：只有 Windows 系统才能运行。绿色打包，一键安装。*

### 从源码构建

#### 环境要求
1. [.NET 8.0 SDK](https://dotnet.microsoft.com/zh-cn/download/dotnet/8.0)
2. [Godot 4.6+ (.NET 版)](https://godotengine.org/download) — 必须选择带 `.NET` 标识的版本

#### 构建步骤
1. 用 Godot .NET 版打开项目文件夹
2. 菜单栏 → `项目` → `工具` → `C#: Build Project`
3. 按 **F5** 运行

#### 打包分发
1. 安装 [Inno Setup 6](https://jrsoftware.org/isinfo.php)
2. 先通过 Godot 导出项目到 `builds/` 目录（参考 [打包导出文档](docs/04_打包导出.md)）
3. 用 Inno Setup 编译项目根目录的 `installer.iss` → 生成安装器到 `builds/installer/`

## 🛠️ 技术栈

| 层级 | 技术 | 说明 |
|------|------|------|
| 游戏引擎 | Godot 4.6 | Compatibility 渲染器 (OpenGL)，120fps / 120 ticks |
| 核心逻辑 | GDScript | 状态机、渲染、UI、事件通信 |
| 系统桥接 | C# (.NET 8) | Win32 API 调用 (窗口枚举、任务栏、注册表、进程优先级) |
| 持久化 | ConfigFile | 用户设置和提醒数据存储 |
| 架构模式 | EventBus + FSM | Autoload 全局事件总线 + 有限状态机 |

## 📁 项目结构

详细的项目架构说明请参阅 [项目架构文档](docs/01_项目架构.md)。

```
├── main.gd                    # 主系统 (窗口 + 边界 + 幽灵墙 + 穿透管理)
├── core/                      # 核心工具层 (Autoload 单例)
│   ├── event_bus.gd           # 全局事件总线
│   └── settings_manager.gd   # 持久化设置管理器
├── entities/pet/              # 宠物实体
│   ├── pet.gd                # 控制器 (FSM + 渲染 + 眼球)
│   ├── eye_behavior.gd       # 瞳孔行为控制器
│   └── states/               # 状态机 (idle/walk/drag/fall/jump)
├── ui/                        # 界面层 (右键菜单 + 提醒系统)
├── interop/                   # C# 系统桥接层
│   └── WindowsManager.cs     # Win32 API 封装
└── docs/                      # 开发文档
```
