# 🐾 Godot Desktop Pet — 赛博机械单眼系统

基于 Godot 4.x (.NET) 构建的桌面物理级全息电子宠物。它拥有绝对真实的物理弹射引擎、纯算法渲染的极光拖尾，以及——**操作系统级别的桌面穿透攀爬能力**。

## 🔥 核心黑科技

*   **赛博视界流光**：摒弃传统 Sprite 贴图！全权依靠纯代码数学公式偏移渲染出极具光泽感的高解析度单眼；拖尾随重力自适应渐变，带给你丝滑到灵魂震颤的 144Hz 分辨率质感。
*   **物理破壁攀爬体验** (C# 驱动)：完美打通 Windows `user32.dll` 底层架构。宠物能且只会在你当前可见的其它软件窗口（例如 VS Code、网页或微信）表面跳跃、滑行或撞击反弹，真正实现“打破第四面墙”。
*   **Windows 性能守门员**：利用 **Z-Culling 深度遮蔽剔除算法**与 **8 像素网格栅格化(Spatial Quantization)** 巧妙过滤操作系统渲染底层的 DWM 残像灾难。就算你狂甩鼠标，这只猛兽对系统的渲染负载仍然静如止水。
*   **深潜隐匿模式**：告别碍眼的底栏状态。自带 `WS_EX_TOOLWINDOW` 底层系统属性并融入 Windows 右下角系统托盘。需要叫醒它？或者让它安静长眠？右下角托盘随时为你敞开。

## ⚙️ 如何游玩与体验

由于引入了极为暴力的桌面窗口爬行动力学，当前项目全面进化为了双端并行的 **GDScript + C# (.NET)** 混合强交互架构。

### 运行环境先决条件
1. 下载并安装 [Microsoft .NET 8.0 SDK](https://dotnet.microsoft.com/zh-cn/download/dotnet/8.0)。
2. 前往 Godot 官网下载带有 **`Godot Engine - .NET`** 标识的超频引擎包。 (绝不能使用 Standard 纯净版)

### 编译与发射
1. 用上述 `.NET` 版的 Godot 导入并打开项目文件夹。
2. 首次运行前，点击编辑器最上方菜单栏的 `项目(P)` -> `工具(T)` -> `C# : Build Project` 确保底层破壁侦听代码完美通过编译。
3. 敲下神圣的 **`F5`** 键！

## 🎮 操控指南

| 操作指令 | 反应结果 |
|------|------|
| **鼠标左键死死按住它** | 切入“引力拖放”模式 (弹簧极速回拉) |
| **右下角系统托盘菜单** | 销毁或唤醒控制 |
| **将其他窗口猛力拖拽砸向它** | 产生清脆的剧烈反弹坠落 |
