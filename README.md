一只活在你桌面上的赛博机械生物。它能在你的应用程序窗口之间跳跃、奔跑和滚动，完全遵循物理定律——包括重力、碰撞和弹性。纯代码渲染，零贴图依赖。

> ⚠️ **仅支持 Windows 平台**：深度调用 Win32 API 进行窗口枚举、DWM 穿透和任务栏屏蔽，暂不兼容 Mac 与 Linux。

## ✨ 核心特性

### 🎯 物理驱动的行为系统
- **真实物理引擎** — 宠物是完整的 `RigidBody2D` 实体，一切移动基于力和冲量，没有预设动画轨迹
- **6 态状态机** — 待机 → 行走 → 跳跃 → 掉落 → 拖拽 → 撤退，行为自然流畅
- **步态风格** — 蹦跳为主 / 滚动为主 / 混合平衡 三档可切换，8% 概率触发自主巡航特殊事件
- **弹簧力拖拽** — 按住宠物拖动时，它会像弹簧一样弹性跟随鼠标
- **反重力模式** — 一键翻转重力方向，宠物挂在天花板上行动

### 👁️ 纯代码科幻视觉
- **零贴图渲染** — 所有视觉效果由数学公式实时绘制，无任何外部图片资源
- **智能瞳孔追踪** — 眼球跟随鼠标移动，静止后切换为自主好奇游走。滚动/撤退时注视移动方向
- **机械虹膜眨眼** — 模拟机械快门的收缩式眨眼动画
- **全息光带拖影** — 高速运动时产生 HSV 色彩空间的渐变彩色拖影
- **虹彩冲击波** — 碰撞时爆发扩散的彩虹光环特效
- **能量共鸣弧** — 多宠物距离 < 150px 时自动绘制锯齿闪电弧，双色渐变辉光

### 🧬 克隆分身系统
- **最多 6 个实例** — 召唤最多 5 个分身，每个拥有独立状态机和物理碰撞
- **动态不撞色** — 每个分身自动分配随机色调 (色环距离 ≥ 29°)
- **告别退出动画** — 分身逐个弹出告别气泡 → 滚出屏幕旋转淡出 → 原体最后离场

### 🎨 自定义颜色系统
- **HSV 色轮选色** — Canvas 实时绘制的色轮 + 拖拽选色 + S/V 滑块
- **三目标独立调色** — 原体 / 分身 / UI 界面分别自定义
- **8 个预设色** + 撞色检测提示 (色调距离 < 6%/10%)
- **全局主题联动** — UI 界面色实时驱动菜单、面板、气泡的边框色

### 🪟 桌面窗口交互
- **窗口感知** — 通过 Win32 API 实时获取桌面所有可见窗口的位置和层叠关系
- **三种交互模式**：
  - 🌍 **自由漫游** — 宠物自由站在窗口的顶部和底部边缘
  - 🔒 **窗口封闭** — 多边形合并算法计算不规则外边界，宠物被困在窗口内部
  - 🚫 **窗口排斥** — 宠物无法进入窗口区域，被窗口推开
- **Z-Order 遮挡裁剪** — 被上层窗口遮挡的踏板区域精确切割，不产生错误碰撞

### 💬 交互与通知
- **戳一戳系统** — 短按宠物触发优先级路由：未确认提醒 → 久别重逢 → 深夜关怀 → 连戳吐槽
- **宠物碎碎念** — 对齐系统时钟整点/半点主动关怀，30/60 分钟两档
- **定时提醒** — 自定义拨轮时间选择器 + 单次/每日切换 + 宠物头顶气泡通知
- **本地定向气泡** — 每宠物独立堆叠 (最多 3 条)，弹簧弹入 + 淡出上飘

### 📊 HUD 信息面板
- **悬浮 HUD** — 宠物侧边的实时信息卡片，常驻/悬浮双显示模式
- **系统时钟** + **WiFi SSID 显示** (点击直接打开网络设置)
- **信息侧栏** — 右键菜单旁显示日期/时钟/WiFi/电池/开机时长
- **系统信息气泡** — 终端扫描风格五段着色报告 (身份/硬件/存储/运行时/网络)

### 🔧 系统集成
- **DWM 完美穿透** — 绕过 `SetWindowRgn` 视觉裁剪限制，特效完整显示 + 精确鼠标穿透
- **开机自启动** — 一键注册到 Windows 注册表
- **系统托盘常驻** — 隐藏任务栏图标，安静运行
- **设置全持久化** — 所有偏好、颜色、提醒、克隆数量跨重启保存
- **Inno Setup 安装器** — 一键打包分发

## 🕹️ 操作说明

| 操作 | 效果 |
|------|------|
| **左键短按** | 戳一戳 — 触发对话 (优先级路由: 提醒确认 → 久别重逢 → 深夜关怀 → 吐槽) |
| **左键长按拖动** | 弹簧力跟随鼠标，松手后自然下落 |
| **右键单击** | 呼出控制菜单 — 分区徽章布局，信息侧栏，完整设置面板 |
| **调整窗口** | 宠物实时感知窗口变化，自动将窗口边缘作为着力点 |
| **退出** | 右键菜单「退出」或系统托盘右击 — 触发告别退场动画 |

## 🏗️ 技术架构

```
Desktop_Pet/
├── core/          ← 全局单例 + 子管理器 (EventBus / Settings / GhostWall / HitRegion / Clone / Farewell)
├── entities/pet/  ← 宠物实体 (FSM 状态机 + 5 个 RefCounted 子系统)
├── ui/            ← 界面层 (右键菜单 + 5 个子模块 / 提醒面板 / 主题面板 / HUD)
└── interop/       ← C# 系统桥接 (Win32 API: user32 / dwmapi / gdi32 / kernel32)
```

### DWM 穿透方案

本项目采用了一种**非主流的穿透方案**: 通过 C# 层手动注入 `WS_EX_LAYERED` 窗口样式 + `SetLayeredWindowAttributes(255)` 使 `WS_EX_TRANSPARENT` 切换生效，从而绕过 Godot 内置的 `window_set_mouse_passthrough` / `SetWindowRgn` 方案的视觉裁剪限制。

> 主流 Godot 桌面宠物项目普遍使用 `DisplayServer.window_set_mouse_passthrough()` 配合多边形区域实现穿透，但这在 Windows 上本质上调用的是 `SetWindowRgn`，**会裁剪多边形外的所有渲染内容** (包括全息拖影、冲击波等超出宠物本体的视觉特效)。
>
> 本项目的方案不需要定义多边形裁剪区域，窗口完整渲染不受影响，穿透仅通过 `WS_EX_TRANSPARENT` 标志位的动态切换实现。代价是需要引入 C# (.NET) 层调用 Win32 API。
>
> 需要说明的是，`WS_EX_LAYERED` + `WS_EX_TRANSPARENT` 本身是 Windows SDK 的标准文档技术，并非独创发现。本项目的价值在于: 诊断出 Godot Compatibility/OpenGL 渲染器默认不设置 `WS_EX_LAYERED` 这一特定前提，并将其应用于桌面宠物场景以解决视觉特效裁剪问题。

技术细节请参阅 [`docs/01_项目架构.md`](./docs/01_项目架构.md)。
