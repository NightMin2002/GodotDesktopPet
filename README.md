# 🔮 Desktop Pet — 桌面机械单眼宠物
![Platform](https://img.shields.io/badge/Platform-Windows_10%2B-blue?logo=windows)

一只活在你桌面上的赛博机械生物。它能在你的应用程序窗口之间跳跃、奔跑和攀爬，完全遵循物理定律——包括重力、碰撞和弹性。

> ⚠️ **仅支持 Windows 平台**：基于 Godot 4.6 (.NET) 构建，由于其深度调用了 `Win32 API`（进行底层窗口枚举机制、任务栏穿透屏蔽等），故暂不兼容 Mac 与 Linux！

---

## ✨ 核心特性

### 🎯 物理驱动行为
- **真实物理引擎**：宠物是一个完整的 `RigidBody2D`，一切移动基于力和冲量，不存在预设动画轨迹
- **5 态状态机**：待机 → 行走 → 跳跃 → 掉落 → 拖拽，行为自然流畅
- **弹簧力拖拽**：按住宠物拖动时，它会像弹簧一样跟随鼠标弹性运动

### 👁️ 科幻视觉系统
- **纯代码渲染**：不使用任何贴图素材，全部视觉效果由数学公式实时绘制
- **智能瞳孔追踪**：眼球自动跟随鼠标移动，鼠标静止后切换为自主好奇游走
- **机械虹膜眨眼**：模拟机械快门的收缩式眨眼动画
- **全息光带拖影**：高速运动时产生 HSV 色彩空间的渐变彩色拖影
- **虹彩冲击波**：高速碰撞时爆发扩散的彩虹光环特效

### 🪟 桌面窗口交互
- **窗口感知**：通过 Win32 API 实时获取桌面所有可见窗口的位置和层叠关系
- **三种交互模式**：
  - 🌍 **自由漫游**：宠物可以自由站在任何窗口的顶部和底部边缘
  - 🔒 **窗口封闭**：宠物被困在当前所在的窗口内移动
  - 🚫 **窗口排斥**：宠物无法进入窗口区域，但可以从内部离开
- **Z-Order 遮挡裁剪**：被上层窗口遮挡的踏板区域会被精确切割，不产生错误碰撞
- **最大化窗口过滤**：自动忽略全屏/最大化窗口，避免误封锁

### ⏰ 实用功能
- **定时提醒**：设置自定义时间提醒，宠物头顶弹出金色气泡通知
- **开机自启动**：一键注册到 Windows 注册表实现开机启动
- **系统托盘常驻**：隐藏任务栏图标，在系统托盘安静运行
- **设置持久化**：所有偏好设置跨重启保存

## 🕹️ 交互操作说明

| 触发方式 | 功能说明 |
|------|------|
| **鼠标左键长按** | 拖动以调整位置；松开鼠标后该单位会受重力设定影响自然下落。 |
| **鼠标右键点击** | 呼出控制面板。用于管理如下设置：<br>• 开关“眼球跟随指针”及碰撞视觉特效<br>• 调整该程序在屏幕边界及窗口边缘的交互模式（漫游/封闭/跨越）<br>• 控制其主动响应功能状态（行动/静默等待）<br>• 配置整点提醒、消息闹钟及程序随系统自动启动项 |
| **调整其它窗口** | 系统支持自动监测前台开启的可见窗体范围。当您拖动或改变浏览器等其它软件大小时，该单位会自动将其顶部与两侧边缘作为着力点进行接触。 |
| **结束运行** | 通过右键面板点击“退出”，或在系统托盘右击对应图标以结束进程。 |
